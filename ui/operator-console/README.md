# Рабочее место оператора · макет 01

Интерактивный макет для согласования интерфейса Simple-Scada. Все значения
модельные, связь с OPC, ПЛК, HMI, модемом и MySQL отсутствует. Кнопка
«Подтвердить в макете» изменяет только модель в браузере. Это отдельный
HTML-предпросмотр, а не установленная копия SCADA10.

## Открытие

Из корня репозитория, без установки дополнительных пакетов:

```powershell
powershell -NoProfile -File .\tools\Build-OperatorPreview.ps1
Start-Process .\artifacts\operator-ui-preview-01\operator-preview.html
```

Либо `python tools/build_operator_preview.py`. Получается один HTML с CSS,
JavaScript, каталогом и значками внутри; интернет не нужен. HTML и снимки
экрана — воспроизводимые результаты, в Git не включены.

Если корпоративная политика браузера запрещает `file://`, обслужите **только
каталог результата** через loopback:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory artifacts/operator-ui-preview-01
```

Откройте `http://127.0.0.1:8765/operator-preview.html`. Сервер нужен только
для просмотра, завершение — Ctrl+C. Он не подключается к оборудованию.
Для синхронизации окон используйте один браузерный профиль и один origin;
другая схема/порт/профиль — отдельное хранилище. Поведение локального
хранилища при `file://` зависит от браузера; в облаке проверен HTTP-вариант.

## Что можно проверить

- Общий обзор: группа, поиск, состояние, режим, давление, уставка, насосы,
  возраст данных; карточка станции и кнопка отдельного окна.
- Карточка: давление, общая уставка, АВТО/СТОП/РУЧНОЙ, состав насосов,
  частота/ток/код ПЧ, события и независимая информация о связи.
- Аварии: общая лента или выбранная станция, активные/снятые/
  неподтверждённые, важность и подтверждение без снятия причины.
- Графики: сравнение станций, 1/6/24 ч, масштаб времени, уставка,
  отдельные шкалы частоты/тока, курсор мышью или стрелками, экспорт CSV.
- Настройки: каталог, группы, профиль, количество насосов, привязка,
  пороги отображения, импорт/экспорт JSON. Выберите роль «Наладчик».

Переключатель роли демонстрирует доступность элементов; это **не система
авторизации**. Пароли нигде не запрашиваются. Настоящие права SCADA остаются
отдельной задачей нативной интеграции.

## Новые станции

«Настройки → Добавить станцию»: постоянный ID, название, группа, профиль,
количество насосов, подключение и уникальный префикс. Запись сразу
используется всеми окнами. Страница вручную для каждой станции не создаётся.
Новая запись получает «нет данных»; каталог не создаёт OPC-теги и не
настраивает модем. Одинаковые привязки и неподдерживаемые поля отклоняются.

Исходный каталог — [catalog.json](catalog.json). Правки интерфейса сохраняются
в `localStorage`, экспорт JSON нужен для переноса. Модель уставок и
подтверждений аварий синхронизируется между окнами отдельно от каталога.
При смене станции/роли/привязки или обновлении из другого окна черновик
сбрасывается. Демо-состояние можно очистить в средствах браузера для этого
локального origin; файлы SCADA этим не меняются.

## Исходники и проверки

`model.js` — правила качества/каталога/черновика, `app.js` — представления и
навигация, `styles.css` — оформление, `index.template.html` — оболочка.
Модельное время фиксируется при загрузке. Данные примеров не являются
измерением текущего стенда; архив стенда намеренно пустой. Для неизвестной
привязки прежние значения и аварии не переносятся.

```bash
node --test ui/operator-console/model.test.cjs
python tools/validate_operator_preview.py --browser /usr/bin/chromium \
  --screenshots artifacts/operator-ui-preview-01 --report /tmp/operator-ui-browser-results.json
```

Для второго теста нужны Python Playwright и Chromium. Тест использует
случайный loopback-порт, блокирует и учитывает внешние запросы, закрывает
сервер после проверки. Он не запускает Simple-Scada или оборудование.
PowerShell-сборщик проверен в Linux/PowerShell7.5.4; запуск Windows5.1 и
просмотр на ноутбуке новым макетом ещё не подтверждены.
