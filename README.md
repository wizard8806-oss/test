# Диспетчеризация насосных станций

Исходники и средства подготовки проектов FATEK / Simple-Scada 2.6.15,
профили MasterOPC и независимый служебный опрос TELEOFIS.

Продолжение работы: [передача контекста](docs/HANDOFF.md).
Полный разбор исходных **199 файлов**: [аудит](docs/repository-audit-2026-10-31.json).

Windows-проект на ноутбуке пользователя **отдельный и не синхронизирован**
с этим репозиторием. Файлы здесь не доказывают состояние работающего ПЛК.
Работа в Codex уже идёт в облачной Linux-среде `/workspace/test`.
Проект локальной HMI-панели восстановлен из предоставленной пользователем
копии: [pump_station_4_37.skm](source/hmi/pump_station_4_37.skm), редактор
**SKTool 7.1**, модель проекта **SK-102CE**. Нативная проверка и сверка адресов
с текущим ПЛК пока не подтверждены. См. [описание HMI](source/hmi/README.md).

## Структура

- `source/plc/` — полученные от пользователя проекты 02, 03, 04.
- `source/hmi/` — исходный проект панели SKTool 7.1 и инструкция продолжения.
- `source/scada-seed-2.6.15/` — минимальная исходная заготовка SCADA, без лицензии и скомпилированных скриптов.
- `source/scada-native-07/Pages.spg` — присланные страницы рабочей07; нужны для воспроизведения исправленного установщика08, не полный проект Windows.
- `source/scada-native-08/` — присланные страницы и исходники скриптов08 для проверки кнопок; без профилей пользователей и паролей.
- `artifacts/**/scripts/` — **исходные** Pascal-модули SCADA; это не мусор сборки.
- `artifacts/teleofis-radio-service-02/` — текущий исходник сборщика радиодиагностики и привязка ServiceDiag.
- `artifacts/` также содержит профили тегов, контракты, планы и историю проверок.
- `tools/` — сборщики, шаблоны PowerShell, сравнение PDW, проверки без оборудования.
- `ui/native-console/` — исходники нативного переноса интерфейса в отдельную SCADA11.
- `ui/operator-console/` — автономный макет рабочего места оператора: общие и отдельные окна, аварии, графики, каталог станций.
- `docs/` — текущая передача контекста и исторические исследования.

Архивы, установочные inline-пакеты, скомпилированные SCADA-файлы,
кандидат PDW05 и кэш исключены из Git. Они собираются из сохранённых исходников.

## Установка и проверки в Linux / Codex

Нужны Python 3.10+, Free Pascal 3.2.2 и PowerShell 7 для проверок.
В Debian/Ubuntu установите `fp-compiler`, `curl`, `tar`, `libicu-dev` и `libssl3`
средствами пакетов среды, затем:

```bash
bash tools/setup_dev.sh
python3 tools/run_checks.py --report /tmp/station-checks.json
```

Скрипт установки скачивает PowerShell 7.5.4 в игнорируемую `.local-tools/`
и проверяет SHA256 по файлу выпуска. Можно использовать имеющийся `pwsh`.
Для нестандартных путей задайте `CODEX_PWSH`, `CODEX_FPC` и при необходимости
`CODEX_FPC_UNITS` (каталог `units/x86_64-linux`). Секреты для тестов не нужны.
Проверки собирают отдельную временную копию и не меняют исходники/исторические отчёты.
Они работают с имитаторами и loopback, без подключения к M2M24 или ПЛК.

Дополнительные проверки оригинального загрузчика Editor и .NET Framework:
[инструкция](docs/HANDOFF.md#дополнительные-проверки).
Облачные тесты не заменяют F8/F9 и проверку на Windows.

## Подготовка пакетов для Windows

Для новой копии репозитория выполните сборщики в порядке, указанном в
`tools/run_checks.py:BUILDERS`, из корня репозитория, например
`python3 tools/build_station_mode_display_01.py` **после сборщиков предыдущих стадий**.
Они создают `Install-*.ps1` и `Paste-*.ps1` в соответствующих каталогах `artifacts/`.
Сборка отдельных стадий обновляет их исторические манифесты; для разработки
предпочтителен изолированный `run_checks.py`.

Текущая проверенная копия на ноутбуке — **`codex_diag_10`**: архив MySQL и
одна запись общей уставки4.00бар в R2100/R2360 подтверждены локальным CLI
01.11.2026. В подключении OPC снят только запрет записи; seed в Git сохраняет
ReadOnly=true. [Результат](docs/reports/station10-opc-write-gate-fix-20261101T195057Z.md).
Применение ведущим ПЧ и показание реальной HMI отдельно не подтверждены.
Панель сейчас недоступна, датчика давления нет; пользователь планирует
подключить калибратор для следующих проверок. Это сообщения пользователя,
не новые измерения из облака. Сам push не меняет рабочую Windows-копию.

Стадии06–09 — история подготовки: режим, обратная связь и клиентские
обработчики кнопок. Пакеты отдельных стадий требуют предыдущую копию и не
являются полной установкой рабочей10. Проверенный путь команды остаётся
`PressureSP_Command`→R2100; R2360 — зеркало. Пароли вводятся/хранятся локально.

Новый [макет интерфейса](ui/operator-console/README.md) собирается отдельно:

```powershell
powershell -NoProfile -File .\tools\Build-OperatorPreview.ps1
Start-Process .\artifacts\operator-ui-preview-01\operator-preview.html
```

`python tools/build_native_operator_console_01.py`. Он создаёт установщик
отдельной копии из проверенной10; фактический перенос/компиляция/архив
на ноутбуке — по [заданию локальному CLI](docs/tasks/station11-native-operator-ui.md).
Рабочая10 сохраняется. По локальному отчёту11 открыта и скомпилирована, но
из-за дефектов переходов/вёрстки/шкал ещё не принята;10 возвращена.
[Точечное продолжение](docs/tasks/station11-navigation-layout-followup.md).

официального3.13.17 x64 для текущего пользователя с проверкой SHA256/подписи,
без изменения PATH. Пользователь разрешил эту установку; последовательность
helper → сборка → кандидат11 описана в указанном задании.

Обзор всех станций, карточки и отдельные окна, аварии, графики и настройки
построены из одного каталога. Это HTML с демонстрационными данными, без связи
с оборудованием; работающая10 не изменялась. [Спецификация переноса в
Simple-Scada](docs/ui/operator-console-spec.md). Технологические тренды в
нативной10 ещё не подтверждены этим макетом.

При настройке каждого рабочего места откройте **Options → Simple-Client →
«Имя этого клиента»**, задайте уникальное непустое имя (например,
`SCADA_LAPTOP_01`), сохраните и перезапустите Client. Имя относится к рабочему
месту и сохраняется для всех его станций. При пустом имени09 отклоняет нажатие
с сообщением «Не удалось определить клиент SCADA для этого нажатия».
После настройки сначала проверьте только черновик `+`/`−` и `Отмена`.
