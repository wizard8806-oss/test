# Native Main r20: материалы для переноса

Это служебная логика, статическая графика и схема размещения, не готовый
SKM. Новый native r19 пока создаётся локальным Codex. Пользователь утвердил
перенос Main поверх его результата, в том же сеансе после завершения r19.

- `main-3-static-no-title.png`: фон без живых значений/статусов/кнопок и
  без «Насосная станция». Поставить Static Picture на0,0,800,480.
- `layout-3.json`:49областей native-контролов с источниками и видимостью.
  Большая уставка и меньшая частота ведомых сохранены. Проверить fonts в
  native Simulator; увеличенный PNG не подтверждает реальную читаемость.
- `main_overview.c`: HMI-сводка, вызов ПОСЛЕ PumpAnimation. Добавить
  READ ONLY Batch16 `MainModeData` R2300/2bytes и `MainRotationData`
  R2140/24bytes до последнего BootAckW; alias/MacroInit генерирует SKTool.
  Не добавлять scalar-inputs и не прописывать pVar вручную. При отсутствии
  alias C явно не компилируется, чужое значение не подставляется.

`tools/prepare_modern_main_macro_r20.py` экспортирует полный C из двух
согласованных зеркал фактического r19 и добавляет сервис/вызов. SKM и
variable-table не пишет. Прежний UTF16-source точно восстанавливается
обратным преобразованием. Обязательны sourceSHA/header17pages/7groups и
r19markers. Fixture-опция только для16-страничного ancestor-теста.

| Адрес | Смысл |
|---|---|
| LW970 | Число подтверждённых RUN-state2 в LW903..905 |
| LW971 | Все3состояния известны; при0 общий счётчик показывает прочерк |
| LW972 | 1PLC/link/mapOK;2нет связи;3неверная карта |
| LW973 | 0unknown,1off,2countdown,3wait,4stop-for-change,5prepare,6no-reserve,7error,8bad-interval,9paused |
| LW974/975 | Часы/минуты до плановой смены |
| LW976/977 | Общее оставшееся время/видимость countdown |
| LW978/979 | Маркер27135/достоверность общей связи и карты |

Время — R2140−R2151 только при правильной фазе/режиме, своего HMI-таймера
нет. R2300=12 — разрешённый AUTO по nativePLC. Фазы R2150 соответствуют
60.RT-сетям r15/r16. Сервис пишет только LW970..979, не команды/PLC/биты.

Сохранить **ND3014/NE5002 дляR2100 и ND3018/NE5004 дляR2110**: оба
имеют показ+штатный ввод. Старое задание ошибочно называло блок частоты
ведомых полностью read-only; это исправлено. Сохранить data types, scale,
limits, visibility/защиты. R2110:200..500, одна дробная цифра. Pressure/SP
имеют source×100; не менять разрядность так, чтобы500 превратилось в50.0.

Сохранить существующие Main AUTO-reason/паузы восстановления и настоящий
Alarm Display. Освободившееся слева место заголовка пригодно для прежнего
активного сообщения ожидания/пуска, нормальное состояние пустое. Постоянную
надпись «Насосная станция» не возвращать. Остальные17страниц/РКФ/ручное
окно/звук/маршруты/сбросы и работа r19 сохраняются.

Host-тест `python3 tools/validate_main_overview_r20.py`:38кейсов, включая
unknown/связь/границы/режим/фазы и отсутствие записей вне LW970..979.
Это не nativeCompile/GUI/RS485. Native Open/Compile/Save/Simulator и
отсутствие тестовых подмен в финальном SKM ещё проверить локально.
