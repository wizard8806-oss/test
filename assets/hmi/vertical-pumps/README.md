# Выбранные фоны HMI: 2, 3 и 4 насоса

Пользователь утвердил этот комплект 06.11.2026: вертикальные синие насосы
с серебристыми корпусами, один нижний серебристый коллектор, тёмный фон.
Верхняя труба с ответвлениями и две задние стойки удалены.

| Установлено насосов | Изображение |
| --- | --- |
| 2 | `pumps-2.png` |
| 3 | `pumps-3.png` |
| 4 | `pumps-4.png` |

Оригинальное разрешение PNG указано в manifest.json; все три имеют один
размер и соотношение сторон, близкое к 5:3. Для SK-070HE целевой экран — 800×480.
Разместить изображения в одной и той же области через штатные свойства
SKTool. Вместе с изображением согласовать расположение подписей,
показателей и команд насосов для каждой конфигурации.

Источник выбора — подтверждённое установленное количество из ПЛК.
Допуск насосов в AUTO является отдельным параметром и фон не переключает.
Физический адрес количества назначается после проверки карты памяти.

Статус: комплект выбран и сохранён. Импорт в рабочий SKM и переключение
фона ещё не выполнены; локальную ручную HMI-копию необходимо сохранить.
Старые эскизы с горизонтальными насосами не являются текущим выбором.
