# Анимация насосов

`pump_animation.c` — добавка к существующему глобальному макросу250мс.
Только чтение новых сигналов ПЛК; вывод в локальные LW900..908.
Перечень input/состояний: `artifacts/station002-pump-animation-r7/interface.json`.

`PumpStationRotor.ttf` — оригинальная векторная крыльчатка, четыре ориентации
U+E001..U+E004. Графика шрифта предоставлена по CC0-1.0; fsType=0 разрешает
встраивание. Пересборка: `python3 tools/make_pump_animation_font.py`
(fontTools требуется только при пересборке самого шрифта).
Не устанавливать случайный сторонний шрифт с похожим именем.

Перед File→Open/Compile нового SKM установить этот шрифт включённым
`tools/Install-PumpAnimationFont.ps1` для текущего пользователя Windows.
Готовая панель получает скомпилированные ресурсы шрифтов от SKTool;
установка TTF в Windows сама по себе не подтверждает их встраивание в HMI.

`preview.html` — интерактивный браузерный макет с демонстрационными данными.
Открыть через обычный HTTP-сервер корня репозитория. Он использует прежний
фон `../vertical-pumps/pumps-3.png` и не связывается с оборудованием.
Это отдельный предпросмотр, не эмулятор протокола ПЛК и не SKTool Simulator.
