# Дизайн нативной HMI «Бабанов»

## Область и ориентир

Этот контракт относится к Main r20 для трёх насосов SK-070HE, 800×480.
SCADA и остальные страницы HMI не получают новый стиль автоматически.
Согласованный ориентир — тёмный матовый вариант №1:
[спецификация](docs/ui/station002-main-modern.md),
[раскладка](assets/hmi/modern-main-r20/layout-3.json).
Последнее уточнение пользователя: без «Насосная станция», крупнее уставка,
меньше частота ведомых. Дизайн для2/4насосов пока только образцы.

## Визуальная система

Канонические поверхности и декоративные насосы находятся в
`assets/hmi/modern-main-r20/main-3-static-no-title.png`; это фон без живых данных.
Native Static Picture размещается0,0,800,480. Каноническая геометрия/размеры
шрифта — `layout-3.json`, с проверкой реального native rendering.
Нормативные ориентиры палитры: фон#26343F, панели#344854, текст#F4F7F8,
вторичный#C4D0D6, голубой#5BA8D0. В native RGB:52/72/84 и244/247/248.
Подтверждённая работа использует прежний native зелёный50/209/125;
неизвестность — вторичный цвет, потеря связи — красный, неверная карта — жёлтый.
Текст остаётся Arial, а символы вентилятора — установленный Pump Station Rotor.
Показания имеют приоритет над декоративным изображением насоса.

## Поведение и владельцы

Авторитетный контракт поведения —
[native-задание](docs/tasks/station002-main-modern-r20-local.md) и сохранённая r19,
а не демонстрационные числа на PNG. Native SKTool владеет цифровыми показами,
вводом/клавиатурой, состояниями, полосой аварий и переходами. Картинка владеет
только фоном, статическими подписями и декоративными насосами.

- R2100/NE5002: прежний ввод/guards/limits, показ в масштабе /100.
- R2110/NE5004: прежний ввод200..500raw, показ с одной дробной цифрой.
- F/I каждого ПЧ: сохранить r19 bindings и отдельную достоверность.
- Недостоверные данные: прочерк/«Нет данных»; достоверный ноль:0.0.
- Зелёный вентилятор — только подтверждённая работа.
- Автосмена берёт время/фазу из ПЛК через MainOverview, своего таймера нет.
- Native Alarm Display сохраняется. Общий статус «Аварий нет» допускается
  только по настоящему LW800=1; связь/карта отображаются отдельно.
- Все семь переходов, РКФ, ручное окно, звук/mute, сбросы и остальные страницы
  сохраняют поведение r19. Главный экран не добавляет команд ПЛК.

## Проверка

Целевая платформа — фиксированная native-панель, не браузер. Проверка выполняется
в SKTool Compile и Offline Simulator800×480: нормальный режим, ноль, один unknown,
потеря связи/карта, останов, countdown/paused/no-reserve/off, ввод и переходы.
Синтетические значения допустимы только в отдельной TEST_ONLY копии.
Финальный native повторно открывается с диска без тестовых подмен.
Истинные RS485, аварийное событие и поведение на панели подтверждаются отдельно;
ни PNG, ни host C-тест не заменяют эту проверку.
