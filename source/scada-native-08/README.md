# Сохранённые файлы рабочей SCADA08

Пользователь предоставил `Pages.spg` и `Scripts.ssc` после проверки
авторизации: +/- по-прежнему не изменяли черновик и не показывали сообщений.
Оба исходных файла сохранены без изменений; SHA256 закреплены в resources.json.

В страницах38 объектов; четыре OnClick-ссылки3,4,5,6 сохранились. В Scripts.ssc
все семь записей, четыре правильных обработчика и модуль08; исходный модуль
байт-в-байт совпадает по тексту с подготовленным. В метаданных имеются ссылки
компилятора. Это не проверка выполнения OnClick/ролей в Windows.

Пакет09 сохраняет страницы полностью, меняет только модуль и четыре обработчика:
контекст клиента считывается в OnClick и явно передаётся в модуль. Прочие файлы
рабочей08, включая локальные настройки пользователей, копируются на ноутбуке.
Сами пользовательские профили/пароли не запрашивались и здесь не сохраняются.
Эти два файла не являются полной синхронизированной Windows-копией проекта.
