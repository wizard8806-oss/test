# Страницы рабочей SCADA07

Пользователь предоставил `Pages.spg` после отказа установщика08
`Station pages differ from codex_diag_07; source preserved`.
Это исходный файл с ноутбука, сохранённый без изменений: 8417 байт,
SHA256 `33d794bc074ec17957e1c696ebce0b133fcfb75c40d5d0dc3504852764971f87`.

Сравнение с генерируемыми страницами07 и загрузчиком официального
Editor2.6.15 показало 36 перенумерованных UID (страницы, подстраницы,
32 текстовых объекта) и одно служебное поле второй страницы 0→1.
Остальные байты, включая подписи, координаты и связи событий, совпадают.
См. `artifacts/station-setpoint-control-01/page-source-review-2026-10-31.json`.

Установщик08 принимает только два проверенных SHA и выбирает соответствующие
страницы08. Для этого варианта сохраняются исходные UID и служебное поле;
добавляются шесть элементов управления и перемещается нижняя строка статуса.
Изменённые пользователем страницы по-прежнему отклоняются.

Это только файл страниц. Полного рабочего проекта Windows здесь нет;
получение файла не подтверждает F9/запуск08 или синхронизацию ноутбука.
