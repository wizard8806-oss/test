# Main r21: ручное управление под карточками насосов

24.11.2026 пользователь поручил убрать «Диагностику» с Main и при включении
ручного режима разместить отдельные пуск/стоп и задание частоты каждого
насоса вместо строки «Ведущий». Основа — существующая native r20,
SK-070HE800×480,3насоса. Это спецификация следующего изменения, не готовый SKM.

**Утверждено24.11.2026:** «отлично. сохраняем и делаем».
Приступить к native-переносу итогового варианта с3контролами на насос.

Показанные пользователю эскизы:
[MANUAL](assets/station002-main-manual-r21/main-manual.png) и
[AUTO](assets/station002-main-manual-r21/main-auto.png).
Числа иллюстративные; PNG не заменяет native-контролы.
В ручном эскизе верхнее поле подписано «Частота ведомых AUTO», чтобы
различать сохранённое задание R2110 и три ручных задания под насосами.
Этот суффикс не меняет binding/scale/guards существующего поля.

## Компоновка

- Main сохраняет давление, крупную уставку, фактические F/I, вентиляторы и шкалы.
- Подпись состояния каждого насоса отделена от делений и полосы частоты:
  подпись y296..310, деления y315..325, полоса y330..338.
- В ручном режиме под каждой карточкой один ряд:
  **Пуск · Стоп · 25.0 Гц**. Число — индивидуальное задание;
  фактическая частота остаётся крупным показанием в карточке выше.
  Ввод подтверждается штатной клавиатурой NumericInput и записывает
  только своё R2180..2182; ПЛК проводит изменение через существующую
  ручную очередь. Подтверждение частоты не выдаёт команду Пуск.
- В остальных режимах остаётся штатная строка ведущего/автосмены/состояния.
  Переключение двух групп занимает одну и ту же область; скрытые кнопки
  не принимают нажатия. Полоса аварий остаётся отдельной и видимой.
- FooterMain содержит6прежних переходов в порядке: Насосы, Каскад, Ротация,
  Ручной, График, Аварии. «Диагностика» удаляется только с Main;
  сама страница4 и остальные пути к ней сохраняются.
- Нижние кнопки: тонкая рамка1px, приглушённый серо-синий фон, без объёмной
  фаски. Не подсвечивать «Насосы» как текущий экран Main: это переход на6.

Геометрия размещения — [JSON](../../assets/hmi/main-manual-r21/layout-3.json).
Проектные области800×480; увеличенный PNG служит только эскизом.

В исходном фоне r20 уже запечены деления0..50, серая полоса/Гц и
«Ведущий:». Под новыми native-элементами нужны непрозрачные READ ONLY
подложки из JSON, закрывающие старый рисунок. Новые деления/единица и
«Ведущий:» становятся native-текстом; последняя подпись скрывается вместе
со сводкой в MANUAL. Общая подложка закрывает обе старые нижние полосы,
затем рисуются рамки сводки/ручного ряда и полоса аварий. Сами подложки
не должны принимать касания или закрывать показания/кнопки.

## Существующие команды: переиспользование, не новый протокол

В сохранённом native r17a исследована неизменённая ручная страница7.
Локальный должен сверить те же объекты в актуальной r20 перед клонированием.

| Насос | Пуск | Стоп | Поле частоты |
|---|---|---|---|
| 1 | BB9028 → M380 | BB9032 → M384 | NE9018 → R2180 |
| 2 | BB9056 → M381 | BB9060 → M385 | NE9046 → R2181 |
| 3 | BB9084 → M382 | BB9088 → M386 | NE9074 → R2182 |

Исходный NumericInput имеет1дробный разряд и границы raw100..500
(10.0..50.0Гц). Это ручная частота, не R2110 ведомыхAUTO.
В r20 сохранить фактические тип, масштаб, пределы, формат и условия записи.
Пуск исходно имеет индивидуальный guard M1530/1531/1532; ввод частоты —
M1534. Общие native-проверки связи и контракта R2329 тоже сохраняются.
Операцию кнопки при нажатии/отпускании скопировать полностью, не выводить
тип импульса только по адресу. Стоп копируется из штатной команды Stop;
ни запрос частоты, ни Stop не означают прямую запись RUN-выхода.

Важно: BB9036/BB9064/BB9092 → M1660..1662 — **«Повторить»**, а не
применение частоты. Это проверено по native-подписям и PLC MAN_FAULT_RESET /
MAN_RETRY_CONSUME. На Main эти кнопки не переносить как «Задать».
PLC MAN_NEED_FREQ_1 сравнивает R2180 с подтверждённым R2190; отдельный Apply
не требуется. Первый эскиз с4контролами ошибочен и заменяется3контролами.

## Режим и переход

Режим определяет физический переключатель. R2552/AlarmWords[2] — его
подтверждённый MANUAL, R2300 имеет ручные состояния20/21/22.
Кнопки появляются для ручного режима с сохранением существующих разрешений:
сам показ панели не делает доступным запрещённый пуск/ввод.
При потере связи/карты, AUTO/STOP, неверном или противоречивом режиме
скрыть/заблокировать ручной ввод; не менять PLC-interlock ради интерфейса.

Существующий однократный запрос LB810 при входе в MANUAL направить на Main
вместо Screen7: оператор сразу получает управление под насосами. Сохранить
нулевую первую выборку/Automatic Reset и однократность на эпизод.
Не заставлять Main открываться каждый тик. Страница7 остаётся доступной
по кнопке «Ручной». Памятка РКФ/LB811 и её приоритет при новой аварии
сохраняются; совместный вход MANUAL+авария проверяется отдельно offline.

Переход режима, открытие Main, подтверждение частоты и восстановление связи
не должны сами выдавать Пуск или повторять прошлую команду. PLC/serial/защиты,
нативный сброс, телеметрияr19 и MainOverview остаются прежними.
