# Главный экран четырёхнасосной станции со SCADA

24.11.2026 пользователь переключил работу с упаковки на доработку варианта
с четырьмя насосами. Приоритет подтверждён: «Перенести новый дизайн и ручное
управление, сохранив SCADA». Это изменение HMI, а не замена алгоритма ПЛК.

## Визуальный и платформенный контракт

SK-102CE,10″,1024×600. Ориентир — новый тёмный матовый интерфейс r21c,
отдельные четыре равные карточки. [MANUAL](assets/station4-scada-main-r1/main-manual.png)
и [AUTO](assets/station4-scada-main-r1/main-auto.png) — сгенерированные эскизы,
не фактические native-снимки. Числа на них иллюстративные.

Для переноса подготовлен чистый фон
`assets/hmi/main-four-scada-r1/background-4-static.png`: четыре декоративных
насоса и поверхности, без подписей, цифр, статусов и кнопок. Его нативный
прямоугольник0,0,1024,600; исходный PNG имеет больший размер, указанный в manifest.
Все функциональные элементы рисуются native-объектами, без запекания данных
в изображение. Геометрия — `assets/hmi/main-four-scada-r1/layout-4.json`;
допускается подгонка по actual glyphs и реальному фону при сохранении симметрии.

Цвета ввода наследуются из `headerEditableFields/style` трёхнасосной раскладки
как визуальные токены, не как привязки/алгоритмы. Подписи и числа прозрачные,
без отдельных плашек: разрешённый ввод#8ED8FF, измерения#F4F7F8, запрет#B1BEC6.
Подписи/единицы нейтральные. Зелёные/красные надписи и тонкие контуры настоящих
кнопок Пуск/Стоп, тёмная основа. Arial для текста/чисел; Pump Station Rotor
для ротора при необходимости. На10″ размещение пересчитано под1024×600.

Верх: давление, уставка крупнее общей частоты ведомых, число работающих/4,
компактная связь ПЛК и режим. Подписи на общей линии, числовые группы с
единицами на общей нижней линии; максимумы помещаются. В MANUAL общая
настройка подписана «Частота ведомых AUTO». Общий заголовок «Насосная станция»
убирается. Не помещать внутрь интерфейса служебные SCADA/OPC/версии протокола.

Четыре карточки: роль, подтверждённый статус, частота, ток при проверенном
источнике, ротор, подпись команды/доступности, шкала с нейтральной дорожкой.
Неизвестные данные — прочерк/«Нет данных»; достоверный останов —0.0.
RUN-команда сама по себе не доказывает работу. Четвёртый канал независим.

В MANUAL вместо общей строки ведущего — четыре группы Пуск/Стоп/своя частота,
8кнопок и4ввода. В AUTO/СТОП эта строка возвращается к исходной сводке/условиям;
ручные команды скрыты согласно режиму и исходным guards. Изменение частоты
не выдаёт Пуск. Клавиатуры/масштабы/пределы брать из действующего4-насосного
проекта; не копировать диапазоны3-насосной версии автоматически.

Нижняя навигация: Насосы/Каскад/Ротация/Ручной/График/Аварии, тонкая рамка.
Страницу диагностики сохранить доступной внутри существующего служебного
раздела. Для остальных страниц достаточно согласовать общий фон/обычный
текст; геометрию форм, сигнальные цвета, графики и логику не переделывать.

## Канонические владельцы поведения

| Возможность | Авторитетный владелец |
|---|---|
| Алгоритм4насосов, очередь, защиты, ротация | Фактический4-насосный PLC-проект, без изменений этим этапом |
| Пуск/Стоп/частоты/пределы/нажатие-отпускание | Существующие native-контролы4-насосной ручной страницы; клонировать целиком |
| Ввод и подтверждение | Штатная native-клавиатура, исходные ограничения |
| Режим/однократный ручной переход | Существующий PanelHelpers/PLC Control фактической HMI; меняется только цель на фактический Main |
| Телеметрия и неизвестность | Проверенные источники/условия качества4-насосной базы |
| SCADA, MasterOPC, SQL, радио | Существующие проекты и соединения, без изменения/перезагрузки этим этапом |
| Фон/декоративные насосы | Новый static PNG, не принимает касания и не хранит данные |

## Найденная несовместимость исходников

Архив `source/hmi/pump_station_4_37.skm`:1321227байт,
SHA256 `13cc9f7d1c5fa59d25c0eb871a2deb3e6f1ef6ca5079be2f5828df5f9e8f5867`,
14страниц, SK-102CE/1024×600. Два совпадающих C-зеркала содержат PanelHelpers
и проверки MapVersion31. Это read-only наблюдение Cloud, не native-приёмка.

Последняя подтверждённая SCADA-интеграция использует карту32, R2100 для
команды уставки, R2360 для зеркала, R2554 для версии и R2840 для heartbeat.
SCADA10 принимала уставку ПЛК; отдельное подтверждение ведущего ПЧ не было
получено. SCADA11 позднее показывала тренды; приёмка native-пропусков/свежести
оставалась частичной. Эти результаты не определяют, какой проект активен сейчас.

Поэтому actual4-насосная Windows-пара и её привязки проверяются до переноса
команд. Архив использовать как резерв/донор, не откатывать более новые правки.
В исходных байтах есть R2180..R2183 и M380..M387; рядом с R2183 найден NE9102.
Это строковые свидетельства, не полная проверка направления, операции и guards.
Применить готовые3-насосные PLC r16/макрос целиком нельзя: они fixed-three.
Смена одного литерала31→32 без сравнения всего используемого контракта
также не подтверждает совместимость.

## Матрица проверки

SaveAs/reopen/ScriptCompile/полныйCompile/Simulator1024×600. Минимум: AUTO;
MANUAL; только4-й работает;4-й недостоверен при живых остальных; ноль;
потеря связи/неверная карта; запреты/busy; фактические min/max каждого ввода;
8нажатий/отпусканий на уникальных локальных TEST_ONLY-приёмниках.
SCADA-файлы и PLC должны сохранить исходные SHA. Моментальная запись
команды в ПЛК/SCADA/оборудование к UI-проверке не относится и не выполняется.

Готовый native4 ещё не создан: [исполнение локальному](../tasks/station4-scada-main-r1-local.md).
