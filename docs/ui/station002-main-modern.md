# Главный экран: выбранный тёмный вариант №1

17.11.2026 пользователь выбрал современный матовый серо-синий вариант №1:
«работаем с №1, берём его за основу максимально». Это новый визуальный
эталон главного экрана HMI. Прежние металлические боковые панели,
бирюзовые LCD-плашки и объёмные кнопки в предложенных макетах отклонены.
Светлый вариант №2 также не является выбранной основой. Старые рабочие
файлы сохраняются; выбор макета не означает изменения native SKM.

Размеры и SHA исходных неизменённых PNG — в [manifest](assets/station002-main-modern/manifest.json).

## Что сохранять максимально близко к макету

- Матовые серо-синие поверхности, белые крупные цифры, тонкие разделители.
  Палитра направления: фон #26343F, панели #344854, текст #F4F7F8,
  вторичный текст #C4D0D6, акцент #5BA8D0. При переносе сверять с PNG.
- Три/два/четыре одинаково устроенные карточки в один ряд. Синие вертикальные
  насосы остаются узнаваемыми, но уступают место частоте, току и статусу.
- Верхняя сводка: давление, уставка, число работающих, **частота ведомых**.
  Пользователь поручил поставить её вместо большого блока «ПЛК: связь есть».
  Связь остаётся компактной индикацией в заголовке с текстовым состоянием.
- Общая заданная частота ведомых — прежний read-only **ND3018 → R2110**
  из текущего Main. Это не среднее фактических частот. В карточках остаются
  фактические F каждого ПЧ. При переносе сохранить тип/масштаб/качество ND3018.
- В каждой карточке: номер, роль, статус, зелёный вентилятор только при
  подтверждённой работе, крупные F/Гц и I/А, горизонтальная шкала частоты.
- Далее строка ведущего/автосмены, отдельная заметная строка аварий и все
  семь нижних переходов в прежнем порядке. «График» и «Аварии» сохраняют
  реальные назначения прежних «График давления» и «Аварии и история».

Для 7″ ориентир F/I не мельче30/28px, статусы18px; для 10″ F/I36/34px,
статусы20px. Итог проверять в native Simulator именно800×480/1024×600,
а не только по увеличенному PNG. Кнопки примерно44px высотой на7″,
48px на10″, без перекрытий и обрезания «Диагностика».

## Данные и состояния

Все значения в PNG демонстрационные. Роли, числа, масштабы, анимация,
полоса аварий и кнопки должны быть настоящими native-объектами SKTool;
нельзя загружать картинку с нарисованными45.0/4.8/«Аварий нет» как рабочую HMI.
При неизвестном качестве — прочерк/«Нет данных», нулевое достоверное
значение показывать0.0. Один плохой ПЧ не скрывает достоверные соседние
каналы. Общая связь с ПЛК и качество каждого ПЧ — разные состояния.

Строка автосмены должна опираться на настоящий интервал/счётчик/фазу,
включая «Отключена», «Отсчёт приостановлен», «Ожидание резерва» и «Смена
ведущего». Не переносить06ч20мин константой или запускать отдельный
таймер, расходящийся с ПЛК. Считать наработку/ротацию по существующей логике,
не менять алгоритм управления ради внешнего вида.

Сначала закончить текущую телеметрию r19, затем перенести Main поверх
реального нового native-файла: [задание локальному](../tasks/station002-main-modern-r20-local.md).
Текущий PLC — fixed-three; макеты2/4 сами по себе не создают работоспособный
опрос/управление другим количеством каналов. Новая внешность native пока
не реализована и не проверена. Памятку РКФ/ручное окно/остальные страницы
и исправления телеметрии сохранить.
