## Первый набор только для чтения

Все теги добавляются в существующий codex.Device1: HOLDING_REGISTERS,
uint16 в устройстве → uint32 на сервере, ReadOnly. Адреса вводятся десятичными
так же, как уже работающий2554 для MapVersion; дополнительный+1 не добавлять.
При первоначальной проверке OPC хранит сырые целые, деление на100 делает
представление SCADA после проверки качества.

| Тег | R / адрес в текущем MasterOPC | Значение |
| --- | --- | --- |
| PressurePV_x100 | 2302 | Давление:350 означает3.50бар |
| PressureSP_x100 | 2360 | Действующая уставка давления в тех же единицах |
| PressureSourceOK | 2303 | 1—выбран источник по Modbus,0—источника нет |
| PressureSource | 2308 | 0—источника нет;1…4—номер ПЧ-источника |
| PlcHeartbeatToggle | 2328 | Копия тактового бита,0/1 |
| AlarmLo | 2550 | Младшее слово аварийных признаков |
| AlarmHi | 2551 | Старшее слово аварийных признаков |

Давление: 10.01 копирует R132→R101; символ R101=P5_BAR100 имеет комментарий
«Давление *100»; 95.087 копирует его в R2302. Показания выбираются из первого
пригодного Modbus-источника R130=1…4; 95.103 экспортирует этот номер в R2308.
Уставка: R2100→R2360, одновременно R2100→R110 для программы.

**Ограничение PressureSourceOK:** это наличие выбранного Modbus-источника.
Программа преобразует AI2 ПЧ из200…1000 в0…1600 и ограничивает значения ниже
диапазона нулём, выше—1600. Поэтому флаг1 сам по себе не доказывает исправность
цепи4–20мА. При0 давление надо скрывать, а не показывать0бар. Для контроля
обрыва датчика нужны отдельные подтверждённые признаки/авария900G.

**Ограничение heartbeat:** R2328—бит, а не возрастающий счётчик. При совпадении
периода опроса с периодом бита возможна выборка одной фазы. Не переносить на
него прежний алгоритм CL50S с безусловным тайм-аутом изменения. Для общей
городской модели нужен независимый монотонный номер обновления/цикла.

по объектам учитывать фактический состав оборудования: не создавать аварию
несуществующего/исключённого ПЧ из общего стендового слова.

## Коды самого 900G: найденный пробел

Руководство M-driver M900G/M900M/M900U ver.1.26, стр.50, определяет U0-01
«Код неисправности», адрес1001H. Источник:
https://m-driver.by/wp-content/uploads/2025/11/Manual-M-driver-900G_900M.pdf
SHA25684957452679700c5b34ba1025b522df333f054b7e005fdc396a3c3137f679da1.
В таблице ошибок, стр.58–59, есть Err20—обрыв датчика давления,
Err52—нехватка воды, Err53—избыточное давление.

Обычная таблица R5000 содержит18одиночных чтений, но не чтение1001H.
Блочные чтения состояния по1000H на остановке/при RUN/предварительной
проверке PI захватывают и слово неисправности во временные буферы. Это
не готовый свежий экспорт кода для каждого привода. Обнаруженного
поточного кэша nativeFaultCode1…4 с признаками свежести нет.
Нельзя выдавать D601/D241/D861 за четыре постоянных кода аварий ПЧ.

Следующее расширение программы должно сохранять nativeFaultCode и качество
отдельно для каждого реально включённого ПЧ, проверять принадлежность ответа
адресату и возраст, а также не нарушать очередь текущего опроса/команд.
Общий монотонный heartbeat должен быть независим от CL50S. Адреса новых
полей пока не выделены и программа ПЛК не изменена. Сначала подтверждается
чтение существующих процессных данных через MasterOPC.

По последнему дополнению пользователя в первую проверку добавлены сырая
частота первого ПЧ R2500 и состояние её данных R2510. В руководстве U0-03
частота указана в0.1Гц. Масштаб нельзя заимствовать из имён старых HMI-полей
или предполагать0.01Гц; живой масштаб ещё не сверялся. Подробная карта
частоты всех4ПЧ и план чтения тока: drive-frequency-current-2026-10-29.md.
