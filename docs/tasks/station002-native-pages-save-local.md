# Получить один native SaveAs новых страниц A

**Остановлено новым исходом:** пользователь сообщил ошибку при открытии A,
затем подтвердил, что C открылся. SaveAs A сейчас не выполнять. Следующее
задание — `docs/tasks/station002-native-16pages-from-c-local.md`: из уже
открытого C получить штатный образец с двумя новыми пустыми экранами.

Оба remaining-open контроля дали operator-reported Open FAIL. Локальный
955371a подтвердил их exact размеры/SHA до этого сообщения. Старые контроли
не повторять, очередную production r15f или новые Open-пробы не создавать.
Задание сейчас — **один штатный SaveAs**, чтобы получить точную сериализацию
16 страниц редактором7.1. Нового native-образца макроса не нужно: C_native_alarm_sample
уже получен и открыт, C и обе Batch-таблицы в нём побайтно сверены.

## Найти существующую A

Предполагаемый путь по прежней worktree15b и присланному окну SKTool:

```text
C:\Users\user\CodexProjects\pump-station\.worktrees\station002-open-isolation-local-15b\open-tests\OPEN_TEST_A_PAGES_ONLY.skm
```

Проверить фактическое наличие, размер1436485 и SHA256
`54fd5914991da1a378ce9e9be950feba46407b6b19b24bdc698617adfc561f75`.
Если путь отличается — найти это имя только в существующих worktree15b/15,
сообщить настоящий полный путь. При совпадающей существующей A не пересоздавать
пакет r15b. Если A вообще не найдена или SHA другой, сохранить файлы и сообщить
точный результат; не подменять A полным r15e, C или комбинированной копией.

## Одно сохранение самим SKTool7.1

Оператор ранее подтвердил Open A без ошибки. Сейчас требуется новое действие:

1. Открыть именно существующую A через File→Open. Убедиться в загруженном
   дереве16экранов и наличии Screen15/16; старое имя Screen16 в combobox
   после ошибки не означает загрузки. Не менять экранные объекты/адреса/модель.
2. Выполнить **File→Save As → A_native_pages.skm** в той же папке. Это отдельный
   новый файл: исходную A и пользовательский проект не перезаписывать.
3. Записать полный путь, размер/SHA нового файла. По возможности штатно
   переоткрыть именно сохранённый A_native_pages.skm и отметить результат.
   Если при первом Open A неожиданно возникнет ошибка, SaveAs не выполнять;
   зафиксировать это новое противоречие прежнему PASS, без перебора остальных файлов.

Если GUI доступен агенту — завершить эти штатные действия самому, сохраняя
остальные открытые проекты. Если GUI не виден — дать оператору **проверенный
существующий полный путь A** и короткую инструкцию SaveAs. Отсутствие GUI
не означает, что native Save уже выполнен; не застревать на Tips/невидимых
процессах и не выдавать Python-перезапись за нативное сохранение.

Нужный приватный выход:

```text
C:\Users\user\CodexProjects\pump-station\.worktrees\station002-open-isolation-local-15b\open-tests\A_native_pages.skm
```

Сообщить реальный путь оператору для прикрепления файла в облачном чате.
Если файл уже получен/прикреплён — повторный SaveAs не нужен. Не публиковать
SKM/vendor/JPG или сырые закрытые метаданные в Git. Сохранить исходные файлы.
Не Compile/Simulator/Download/оборудование, ПЛК/runtime/reset/main не менять.
Новый файл — эталон сериализации, не финальная прошивка.
