# Локальный просмотр интерфейса · макет 01

Продолжение [HANDOFF](../HANDOFF.md), ветка `codex/project-handoff-2026-10-31`.
Это просмотр HTML, не установка нативного интерфейса и не новый опыт Apply.
SCADA10, ПЛК/HMI, MySQL, MasterOPC и радиосборщик не менять/перезапускать.

1. Проверить путь/ветку/HEAD/status/index/untracked, прочитать AGENTS/HANDOFF.
   Получить ветку с сохранением местной работы: при чистом дереве и без
   расхождения fast-forward; иначе отдельный worktree. Без reset/clean/
   автоматического stash/перезаписи местных native-файлов.
2. Из этой копии репозитория выполнить `tools/Build-OperatorPreview.ps1`;
   он пишет только `artifacts/operator-ui-preview-01/operator-preview.html`.
   Открыть HTML в браузере. Если `file://` запрещён, loopback-инструкция
   находится в [README](../../ui/operator-console/README.md).
3. Просмотреть обзор, карточку стенда, отдельное окно, аварии, графики и
   настройки. Все значения/действия — модельные. Проверить читабельность
   на фактическом разрешении ноутбука и навигацию; роли в макете не меняют
   пользователей SCADA. Установку Python/браузеров ради этого не выполнять,
   достаточно имеющегося браузера и PowerShell5.1.
4. Сохранить публичный отчёт только о макете: Windows/PowerShell/браузер,
   базовый SHA, SHA/размер HTML, фактически проверенные экраны/ограничения.
   Обновить HANDOFF, опубликовать только согласованные исходники/документы
   в текущую ветку. Игнорируемые HTML/PNG и рабочие native-файлы не добавлять.

Проверка в браузере не подтверждает нативные F8/F9, активный каталог,
архив трендов, показание панели или применение уставки ведущим ПЧ.
Датчика пока нет, калибратор пользователь планирует подключить позже;
во время просмотра интерфейса измерение давления не имитировать в ПЛК.
