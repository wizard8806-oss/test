## Работа локального и завершение

При доступном GUI завершить эти штатные действия самому. Если GUI агенту
не виден, дать оператору короткую последовательность SaveAs/таблицу5групп/
Save/reopen и проверенный путь source. Не застревать на Tips/невидимых
процессах и не заменять создание нашим бинарным скриптом. Сам оператор
уже находится в правильном открывающемся проекте.

Нативный файл не прогонять через with_sequential_alarm_ids или другой
«ремонт». Сначала нужно сравнить его реальные байты, включая IDs/flags,
порядок и companions; успешный Open эталона важнее наших предположений.
При уже полученном файле повторный nativeSave не нужен.

Это эталон формата. Compile/Simulator/Download/Force/RUN/оборудование
здесь не нужны; шкаф отдан. PLC/runtime/reset-guard/main не менять.
NativeSKM/PDW/JPG/vendor/закрытые дампы в Git не публиковать. В компактном
отчёте handoff-ветки отдельно source/path/SHA, сколько групп создано/их
Size/адреса, nativeSave/reopen, реальный путь результата. Обновить HANDOFF.
