## WinProLadder

1. Открыть именно PDW-кандидат в существующем WinProLadder. Сохранить
   другие открытые проекты; не использовать их вместо насосной станции.
2. Выполнить штатную **офлайн-проверку программы/синтаксиса** и просмотр
   памяти. Выбирать проверочную команду по фактическому меню приложения;
   не нажимать неизвестные горячие клавиши или команды связи/загрузки.
   Записать её точное название, ошибки и предупреждения, конкретную сеть
   каждого сообщения. Успех конвертера узлов не заменяет эту проверку.
3. Сверить карту новых ресурсов: R3200..3288, M1815..1839/M1871..1879,
   T124/T125 и сохраняемые R2857..2859, включая косвенные обращения.
   Расчётный остаток программной памяти664байта — записать фактическое
   значение WinProLadder. Модель CPU и работающие сети ради памяти не менять.
4. По программе сверить интерфейс с текущей HMI: fault-profile
   R3049=27120, reset-profile R3200=27131, request R3216..3221;
   сохраняются карта32/R2554 и существующая диагностическая карта27110.
   Разрешение reset по STOP/T51/X8/X9/Y1..4/свежей нулевой частоте;
   READY не требуется. Port3-сервис не подаёт RUN; Port2/CL50 прежний.
   Системный D4044 только читается. Это проверка кода, не онлайн-чтение ПЛК.
5. При успехе сохранить отдельный **station_3p_reset_r15_native.pdw**.
   Записать фактические путь/размер/SHA. Native Save может изменить ключ/
   служебную сериализацию: сравнить программу и таблицы декодированно,
   не требовать равенства зашифрованных файлов. Ключи/полные дампы не выводить.

При реальной ошибке проверки изучить точную сеть/сообщение и исправить
отдельную копию в рамках уже разрешённой функции сброса. Не убирать рабочие
защиты. После изменения повторить целевые byte/host и нативные проверки.

## Если готового PDW нет

Кандидат уже изготовлялся и прошёл43компонентных сценария; сначала найти
его. Только если он отсутствует, получить
`artifacts/station002-plc-reset-native-check/delivery-manifest.json` из того
же коммита, что это задание. Он содержит **только4PLC-файла**, закреплённых
на прежнем проверенном code-коммите. Скачать по rawBase, сверить bytes/SHA,
сохранить tools в отдельном пакете `plc-reset-native-check`.

Восстановление из exact пользовательского PDW-source, только в новые файлы:

```text
python -S -B plc-reset-native-check/tools/build_drive_reset_r15.py --source "ПОЛНЫЙ_ПУТЬ_К_бабанов байтик.pdw" --out station_3p_reset_r15_candidate.pdw --report plc-build-native-check.json
python -S -B plc-reset-native-check/tools/validate_drive_reset_r15.py --source "ПОЛНЫЙ_ПУТЬ_К_бабанов байтик.pdw" --candidate station_3p_reset_r15_candidate.pdw --report plc-check-native-check.json
```

После восстановления сверить206320/de693ad…bb01 и перейти к WinProLadder.
Не скачивать/не запускать старые HMI-builders из отозванного пакета r15.
