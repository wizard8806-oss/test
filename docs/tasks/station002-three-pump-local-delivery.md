# Создать локальную PLC-копию для трёх насосов

Пользователь отложил привычные W85 и поставил приоритет — программа для
станции с3насосами. Выполнить именно генерацию изменённого PDW и сообщить
его путь. Не ограничиваться аудитом/подготовкой. Никаких загрузок в PLC/HMI/
ПЧ, изменений работающей SCADA или публикации native-файла.

## Вход и доставка

Получить `artifacts/station002-three-pump-01/delivery-manifest.json` из того же
закреплённого коммита, что и это задание. Использовать `rawBase` и размеры/SHA
каждого helper; не брать старые версии или HEAD/main вместо указанного pin.
Для генерации нужны только Python3stdlib и8helpers, без GUI/DLL/pip/git fetch.

1. Создать новую доступную папку, например
   `.worktrees/station002-three-pump-local-01/`. Исходники/HP-r1/HP-r2 сохранить.
2. Взять ранее созданный HP-r2 из
   `.worktrees/station002-high-pressure-local-02/station_MC_CM55_900G_24MC_HP_auto_candidate_r2.pdw`.
   Требуется179925байт/SHA256
   `7d436bec9fab5a50bd60ae22e269be90a5adfb9a579426b397a7520c82a82db4`.
   Его F8 уже показан пользователем:0ошибок/25предупреждений. Не требовать
   повторной проверки HP-r2 перед генерацией новой трёхнасосной копии.
3. Если native-save изменил SHA, эту копию сохранить отдельно. Найти точную
   ранее сгенерированную r2 по отчётам/сохранённым source. Если её нет, можно
   воспроизвести точную r2 по уже выполненному заданию c94178b из неизменённого
   source96686b99…01abf5 в новой папке, не перезаписывая native-save.
   Source-lock нового генератора не ослаблять; другой исходник не подменять.
4. Скачать все `files[]` по `rawBase + path`, сохранить исходные байты и
   каталог `tools/`, проверить SHA/размер каждого. Затем продолжить сборку.
5. Из новой папки выполнить установленным Python3:

```text
python tools/build_three_pump_pdw_candidate.py --source "ПОЛНЫЙ_ПУТЬ_К_ТОЧНОЙ_HP-r2" --out station_3p_24MC_HP_auto_r1.pdw --report three-pump-local-build.json
```

6. Проверить результат:184126байт, SHA256
   `a6e9c5c057ad324635c10e73b61f25ceb08604c4651eaaf943880f2dc176c745`,
   `installedPumps=3`, `projectName=PUMP_STATION_3`, `normalPollRows=14`,
   `insertedNetworks=113`,26точечных изменений, source не изменился.
7. Сообщить абсолютный Windows-путь готового PDW, размер/SHA и путь отчёта.
   Затем открыть **новый** файл и выполнить F8, если GUI доступен. Иначе
   передать пользователю только этот недостающий шаг. Старый успешный F8 r2
   не является F8 нового файла. Не утверждать готовность к оборудованию.
   Обычные W85 пользователь сейчас отложил: сообщить итог и не заменять
   доставку/продолжение программы их удалением. Ошибки F8 фиксировать отдельно.

При несовпадении исходника вывести конкретные пути/размеры/SHA; при иной
ошибке — точную команду и сообщение. Не обходить Access Denied, не искать
заново desktop/ПО как замену запуску Python, не перезаписывать существующий PDW.

## Состав результата

Фиксированные3насоса, Y1..Y3; Y4 принудительно сбрасывается.14запросов
основного опроса только к адресам1..3, очереди/проверки адресов ограничены3,
датчик4/STOP4 и его ложные аварии исключены. HP-r2 сохранена: Δ2бар,
срабатывание PV>SP+Δ, автоматический сброс при достоверном PV≤SP.
R2860..2867 — read-only состав3/маска7/картинка1; R2868..2883 защита;
R2900..3000 служебная RAM-таблица, не писать туда из HMI/SCADA.

SKM этой сборкой не изменён. Текущую принятую HMI-r1 сохранить; оформление
под3насоса/поле HP делаются отдельно и не задерживают выдачу готового PDW.
Выбор2/4 сейчас отложен. Полный отчёт:
`docs/reports/station002-three-pump-candidate-20261108.md`.
