## Наблюдение, которое нужно объяснить

В `station002-r20-normal.png` сверху слева «0», в
`station002-r20-unknown-p2.png` — «2». По отчёту это номер тестового сценария.
Но на опубликованном `station002-r20-production-offline.png` также стоит «0»,
хотя отчёт утверждает отсутствие selector в final. Cloud не имеет байтов final
и не может определить, перепутан снимок или в production сохранился объект.
Это не доказанная утечка тестового макроса и не установленный дефект часов.
В layout поле `auto_reason_or_restart` должно быть пустым в обычном состоянии.

## Выполнить

1. Сверь файл на диске с указанными размером/SHA. Если открытый пользовательский
   RAM содержит более новые изменения, сначала сохрани отдельно и сравни;
   не затирай его старой r20 ради совпадения SHA.
2. Открой именно проверенный production-файл через File → Open после другой
   копии. Сними окно редактора с полным путём и отдельный кадр Simulator.
   Установи id/тип/адрес/visibility верхнего левого объекта: откуда берётся «0»?
   Сравни с TEST_ONLY selector и исходным reason/restart. Проверь отсутствие
   тестовых bindings, переназначений входов, тестовых присваиваний и test-hook,
   а не только поиск строки TEST_ONLY в C. Синтетический тест не запускать
   внутри production. Проверить Main и C-зеркала сохранённого файла с диска.
3. Если опубликован неверный кадр — замени только доказательство/отчёт,
   оставь проверенный native без искусственной новой версии. Если это
   сохранённый тестовый объект/неверная видимость — исправь в отдельном
   `pump_station_3p_babanov_r20a_main_native.skm`, сохранив остальную r20.
   У нормального режима не должно быть голого номера сценария. Настоящие
   причины AUTO и отсчёт перезапуска сохранить по исходным условиям.
4. При изменении native: SaveAs → независимый reopen → Script Compile,
   whole-project Compile → Offline Simulator, запиши actual результат.
   Проверь изменённое поле; вводы/маршруты/РКФ не переделывай и не запускай
   заново всю прежнюю матрицу без причины. Проверь, что реальные привязки
   R2500..2/R2510..12/LW960..965, MainOverview и PLC не изменились.
5. Обнови локальный manifest/README и публикуемые отчёт/HANDOFF: точный путь,
   размер/SHA, id/адрес поля, установленная причина, свежий production-снимок.
   Припиши к старому снимку, если он оказался TEST_ONLY. Native и приватные
   полные дампы оставить вне Git. Выдай пользователю полный Windows-путь.
