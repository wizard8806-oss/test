насосов как Static Picture ST0 и прислал сохранённый unified-draft.
Геометрия главной страницы исправлена в приватном кандидате r1. Полного
SKM в Git нет; воспроизвести копию локально проверяемым рецептом.

Материалы: `artifacts/station002-hmi-layout-01/README.md`,
`layout-recipe.json`, `tools/apply_hmi_layout_recipe.py`.
Способ доставки — загрузка двух последних файлов через HTTPS по
закреплённому коммиту в новую разрешённую папку, без записи в Git-метаданные.

1. Найти доступный пользовательский `pump_station_unified_2-4_draft.skm`.
   Требуемый SHA — `7484c9475391201b37d408a68e63233b970a7d33c77e276cdbf7376539a2e5e7`.
   Если доступа нет, назвать пользователю конкретную папку, куда скопировать
   файл. Ограничение не обходить. Если SHA иной — сохранить и сообщить,
   не обновлять pin самостоятельно и не применять к другой версии.
2. Запустить инструмент стандартным Python с source/recipe/out/report по
   инструкции. Выход — новый `pump_station_unified_2-4_layout_r1.skm`,
   SHA `d9f089f09b87fff4cb347664457fbfa171f297defd96a2fd713b65da23f43175`.
   Исходник и существующие результаты не перезаписываются.
3. Сообщить пользователю абсолютный путь новой копии и результат SHA.
   Desktop исполнителя уже диагностирован; повторять общий поиск окон
   или запрещённый запрос расширения доступа для этого шага не требуется.
4. Пользователь открывает новую копию в SKTool и запускает Offline Simulator.
   Проверить читаемость, границы панелей, кнопки/переходы и строку AUTO.
   Сначала принять результат r1; не перезаписывать им прежнюю рабочую версию.
