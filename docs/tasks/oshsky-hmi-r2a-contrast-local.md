   фиктивную правку. Если повторяется — сохранить отдельную HMI r2a.

   фактические страницы. Исправить только повторяющиеся дефекты фона/контраста.

   Логотип и Main не перекрашивать ради этой правки.
5. PLC native r2 сохранить с исходным SHA. Сохранить HMI-макросы/переменные,
