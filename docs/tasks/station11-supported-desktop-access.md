# SCADA11: штатный доступ к видимому Client после диагностики sandbox

02.11.2026 МСК. Продолжение [визуального задания](station11-visual-parity.md).
[Измерение5727a43](../reports/station11-visual-parity-session-diagnosis-20261102.md)
уже выполнено: SessionId1 общий, executor находится на CodexSandboxDesktop,
не elevated; приложения elevated; EnumWindows=false/error0. Видимый терминал
рядом со SCADA не определяет desktop команд. Окна/desktop приложений не
получены; elevation как самостоятельная причина не установлена.

## Одно следующее различающее действие

1. Проверить, предоставляет ли **фактически доступный инструмент исполнения**
   штатный запрос конкретной команды вне песочницы. Для exec_command с таким
   параметром это `sandbox_permissions=require_escalated`; пользоваться
   параметрами реально установленного инструмента, не выдумывать API.
   `require_escalated` — запрос режима исполнения Codex, а не гарантия UAC/
   административного токена, desktop Default или доступа к GUI. Повторное
   общее согласие пользователя на стенд не требуется; инструмент применяет
   собственную обычную проверку допуска.
2. Запросить только **один читающий запуск** точного
   `tools/Get-ScadaUiContext.ps1` из актуальной версии. Обоснование запроса:
   «В sandbox измерен CodexSandboxDesktop и не получены окна SCADA. Нужна
   читающая проверка контекста и окон через штатный режим вне песочницы;
   без кликов, запуска/остановки ПО, OPC/SQL и команд оборудованию».
   Широкое разрешение на произвольные PowerShell-команды не запрашивать.

   ```powershell
   $uiContextOut = Join-Path $env:TEMP ('scada-ui-context-supported-' + [Guid]::NewGuid().ToString('N') + '.json')
   powershell -NoProfile -File .\tools\Get-ScadaUiContext.ps1 -OutPath $uiContextOut
   ```

   Основная копия на5e3cbae грязная и helper не содержит. Предпочтителен
   актуальный отдельный worktree. Если Git-обновление недоступно, допустим
   уже применённый способ: получить точный helper5727a43 через GitHub,
   сверить blob `8e6686a6d113045048ed909b53cb4dd04410f748` и исполнить его из
   новой временной папки. Не менять ACL/.git, не сбрасывать старые изменения.
   JSON вне Git; в отчёт — версия, тип запроса/результат, session/desktop,
   elevation, HWND/размер/DPI и ошибки, без чужих заголовков/секретов.
3. Если штатный режим отсутствует, запрещён настройкой или отклонён review —
   записать точное ограничение/причину и остановить этот путь. Не отключать
   sandbox, не открывать/переключать чужие desktop, не использовать инъекцию,
   task scheduler/службу/RunAs как альтернативный обход. Прежняя ошибка
   FETCH_HEAD Access denied не является отказом этого ещё не выполненного
   запроса; результат запроса не предсказывать по ней.
4. После допуска **сверить измерения**. Если desktop/доступ не изменился или
   окон всё ещё нет — зафиксировать это, не писать, что доступ восстановлен.
   Если появились окна Client — использовать только предусмотренный канал
   просмотра/снимка: операторская область, точная версия/размер/DPI. Не считать
   HWND разрешением на произвольный ввод; управление/переключение проверять
   по действующему стендовому плану. Сам helper изображения не создаёт.

## Возврат к интерфейсу

При доступном штатном захвате получить реальные карточку/обзор Client11 и
сопоставимые эталоны по [контракту](../ui/operator-console-visual-contract.md).
Если доступен только Client10, явно указать это; не подменять результат11.
Исправлять сначала композицию/карточки/типографику/фон/навигацию, сохранить
проверенную логику команд/архива и один десятичный знак. Без нового кадра
не объявлять визуальную приёмку; не тратить следующий проход на те же logs.

Если поддерживаемого захвата нет и запрос не помогает, единственный недостающий
материал для визуального сравнения — чистый снимок операторской области Client11
с видимого desktop. Указать это пользователю одним конкретным сообщением;
не предлагать отключать защиту или запускать всё администратором. Доступные
проверки исходников продолжать самостоятельно, ограничения не выдавать за PASS.

Codex сам сохраняет отчёт/HANDOFF и публикует согласованные изменения в текущую
ветку с проверкой remote SHA. Основная старая Git-копия/SCADA10/ПЛК/HMI/радио02
сохраняются; этот запрос не выполняет полевых команд и не перенастраивает БД.
