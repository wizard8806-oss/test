## 1. Сначала подготовить отдельную копию дисковых файлов

Получить актуальную ветку с сохранением местных изменений и station09 JSONL,
прочитать HANDOFF. **Текущий OperatorConsole в Editor имеет неподтверждённый
несохранённый буфер. Не выполнять Ctrl+S/Compile All/закрытие с потерей буфера
в исходную11.** Подготовка ниже читает только диск и не обращается к Editor.

Использовать установленный Python; из корня репозитория:

```powershell
$probePython = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python313\python.exe'
$probeSource = Join-Path $env:USERPROFILE 'Documents\Simple-Scada 2\Projects\codex_diag_11'
$probeParent = Join-Path $env:LOCALAPPDATA 'CodexCandidates\SCADA11'
$null = New-Item -ItemType Directory -Path $probeParent -Force
$probeToken = (Get-Date -Format 'yyyyMMddHHmmss') + ([Guid]::NewGuid().ToString('N').Substring(0,6).ToUpperInvariant())
$probeId = 'UINAV11-' + $probeToken
$probeTarget = Join-Path $probeParent ('codex_diag_11_probe_' + $probeToken.ToLowerInvariant())
& $probePython -I -B .\tools\prepare_native_ui_event_probe.py --project $probeSource --out $probeTarget --probe-id $probeId
if ($LASTEXITCODE -ne 0) { throw 'Probe preparation failed; source preserved' }
```

Инструмент проверяет известные SHA Pages/Scripts и версию2.6.15,44 привязки;
до копирования закрывает доступ к новому каталогу только владельцу/SYSTEM.
Создаётся отдельная `codex_diag_11_probe_<id>` вне Git. Копируются ресурсы,
Variables/Trends/Project/Servers и архивные настройки из **сохранённой11**.
Из48 скриптов изменяются только OperatorConsole и UiOverview0Nav1_OnClick;
остальные46 записей, все ID/metadata и страницы сохраняются. Старый compiled
cache исключён. Манифест CodexProbeManifest.json приватный, тел кода в stdout нет.

Это не копия RAM-модели Editor и не нативная сборка. При несовпадении SHA,
неожиданной структуре/теле скрипта, ошибке ACL/существующем назначении —
остановиться и описать точный отказ. Не менять pins, не перезаписывать
существующие проекты, не обходить guard. Исходная11 не патчится.

## 2. Сохранить неподтверждённую модель отдельно, затем открыть probe

Перед сменой проекта штатным **File → Save As** сохранить текущую модель
Editor в новый приватный каталог backup с пометкой `UNVERIFIED-unsaved`,
как предусмотрено прежним разрешением на сохранение модели. Это снимок
непроверенного буфера, не новая рабочая версия. Проверить адресата и полный
путь стандартного диалога до подтверждения, не писать поверх10/11/probe и
не компилировать неподтверждённую модель. Сверить, что исходные дисковые SHA11
остались прежними; snapshot сохранить вне Git с манифестом/ACL owner/SYSTEM.

После сохранения модели открыть Project.spr **подготовленной probe** через
штатный файловый диалог. Вложенный текстовый редактор для этого не нужен.
Если надёжное Save As/переключение по-прежнему недоступно, оставить Editor
и его буфер открытыми, сохранить уже подготовленную probe и точно указать
блокирующий штатный диалог/действие. Не выдавать файловую подготовку за опыт
и не терять модель принудительным закрытием процесса.

На probe выполнить штатный Compile All и сохранить. Если для регистрации
Server необходим Save As в Projects — использовать **новое уникальное имя
probe**, сохранить приватность копии и проверить фактический загруженный путь.
Не заменять исходную11 и не угадывать CLI-флаги компилятора. Сверить после
native Save/Compile логические тела46 нетронутых скриптов и настройки архива;
изменения native cache/метаданных Editor описать отдельно.

## 3. Выполнить различающий runtime-опыт

Далее [протокол BOOT/ENTER](station11-live-event-proof.md), **с поправкой**:
временный код уже находится в отдельной probe, вставлять его руками снова
не требуется. Использовать её уникальный probeId из манифеста.

- Перед переключением проверить отсутствие pending-запроса и сохранить
  пассивные значения через существующий MasterOPC. Ранее R2100/R2360=410 GOOD,
  но время было обрезано; свежесть текущего значения этим не подтверждена.
  Не возвращать4,00 автоматически и не нажимать Apply.
- Штатно активировать ровно probe вместо10, подключить Client к её реальному
  пути/имени. Снять начальную позицию Server-log и дождаться **новой BOOT**
  с уникальным probeId. Ни старый лог, ни F9 не подтверждают загрузку этой версии.
- После BOOT выполнить один действительный клик UiOverview0Nav1. Сохранить
  новые ENTER/CLIENT_EMPTY или CLIENT_PRESENT/TARGET_MISSING/BEFORE_HELPER/
  AFTER_HELPER/EXCEPTION, не публикуя имя клиента и полный журнал. Зафиксировать
  фактическую страницу. Если ENTER нет — доставка события всё ещё не доказана.
- Для следующего различающего изменения использовать точечный воспроизводимый
  патч отдельной копии и новый BOOT-ID, если вложенный редактор недоступен.
  Не менять одновременно геометрию/права/метаданные/несколько API по гипотезе.

По завершении штатно остановить диагностическую probe и вернуть рабочую10,
указать реальный активный проект/путь. Probe с диагностикой не принимать как
готовую11; оставить её приватно неактивной. Исходная11 должна остаться чистой
от BOOT/ENTER. Дальнейшая приёмка переходов/журналов/трендов/вёрстки/шкал —
после установленной причины и воспроизводимой поправки основного исходника.

Codex сам сохраняет отчёт/HANDOFF и публикует согласованные исходники/документы.
Отделить PREPARED, native Compile, BOOT и ENTER/переход. Указать судьбу
UNVERIFIED RAM-snapshot, новых копий, дисковые хеши и незакрытые пункты.
SCADA10, ПЛК/HMI, радио02/ServiceDiag9336/7000, БД/профили и старые JSONL сохранить.
