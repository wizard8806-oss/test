# Минимальная нативная запись группы Alarm Login в SKTool7.1

Оператор проверил: CONTROL открывается, A_PAGES_ONLY открывается,
C_MACRO_ONLY открывается; B_ALARMS_ONLY даёт «Illegal opening of configuration
file!». Значит, независимо воспроизводится отказ добавления групп аварий.
Compile/Simulator/оборудование этими ответами не проверены.

D_FULL_WITHOUT_ALARMS у оператора не найден. Не просить его снова открывать
несуществующий путь и не трактовать это как результат nativeOpen. В новом
шаге используется уже открывающийся C. Прежний r15a повторять не нужно.

Нужен один минимальный файл, **созданный самим SKTool7.1**, для сравнения
с известным C. Схема cachedvendor7.0 не доказывает формат текущего7.1.
Это эталон сериализации, а не новая productionпрошивка.

1. Открыть `OPEN_TEST_C_MACRO_ONLY.skm`. Expected1298619байт,
   SHA95e6b3cd163effa7c1624470c8ac870f726b0b30e73175fdec09d8ff9be0d272.
2. File→Save As в отдельный `C_native_alarm_sample.skm`, сохранить исходный C.
3. В левом ProjectManager правой кнопкой по **Alarm Login**, выбрать
   **New digital alarm** (в некоторых переводах Bit Alarm). Создать только
   одну новую группу: Read address **LB1**, Size **1**, сообщение **TEST**.
   Остальные параметры оставить штатными, существующую группу
   «События станции»/R2550 не менять. Если меню/поля отличаются — сохранить
   доступный снимок диалога; не имитировать запись бинарным сборщиком.
4. Сохранить новый SKM. Штатно закрыть/снова открыть именно эту копию,
   убедиться, что она читается без Warning и в Alarm Login две группы.
   Не Compile/Simulator/Download/PLC/hardware ради этого образца.

Если локальному GUI доступен, выполнить этот SaveAs/редактирование на ПК
и зафиксировать новые bytes/SHA. Если GUI недоступен, дать оператору
конкретные эти четыре действия, без очередного Tips/CtrlOцикла. Оператор
уже продемонстрировал доступное окно и успешное открытие C.

Новый SKM нужен облаку приватно для разбора. Nativeфайл/vendor/полные дампы
не публиковать в Git. Локальный может сохранить его рядом с источником
и дать пользователю полный путь для прикрепления в чат. В публичный отчёт —
только compactметаданные и результат nativeOpen.

После получения сравнить nativeдвухгрупповый файл с C и разобраться в
реальном хвосте digitalAlarmProp/каталоге/ограничениях7.1. Не объявлять
добавочные нули или лимит256 доказанными до этого сравнения. Исправить
производитель, пересобрать полный проект с кодами/кнопками и выполнить
nativeOpen/Compile. Сохранять Batch16/BootAckWпоследним и пользовательскую
раскладку/HAD; аппаратуру не затрагивать. C/A открытие не означает готовность
полного проекта. Без кода и расшифровок аварий задача не завершена.
