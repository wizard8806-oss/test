## Автопоказ остаётся частью задания

Проверь уже выполненную работу в r18. Автовызов — на новую подтверждённую
аварию питания B00 entry0 / R2550.0, один раз на эпизод. Можно закрыть;
пока авария активна, принудительно повторно не открывать. После подтверждённой
очистки и нового 0→1 — снова показать. Ручную кнопку оставить.
Не считать потерю/восстановление связи само по себе новой аварией; чтение
с неизвестным качеством не разоружает защёлку. R2526 — пауза, не триггер.

Если логика уже добавлена, не затирай её заменой картинки. Если ещё нет,
заверши в HMI по существующему механизму ручного окна. В документации
r8 он описан как PLC Control LB810→Screen7; сохрани этот рабочий механизм
ручного режима. Не создавать конфликтующих принудительных переходов.
Исходный AlarmSound C имеет SHA e02de39a…61e5; точечное расширение HMI
