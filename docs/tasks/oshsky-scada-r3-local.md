## 2. Проследить actual цепочку данных и составить матрицу

Для каждого логического поля CSV указать actual OPC item/PDU, тип/доступ,
SCADA variable/DecimalOffset/Scaling, producer/объект, качество/heartbeat,
масштаб/единицу/архив, результат и основание. Недостаточно увидеть имя тега.
Чтение через существующий MasterOPC. Второй Modbus-клиент к основному каналу
не запускать. Read-MasterOpcProfile/Read-ScadaVariableMetadata и portable
Layout использовать только в поддерживаемом формате, не угадывать смещения.

Обязательные группы:

1. Map32, R2329=27110, продвижениеR2840, режимR2300, ведущийR2304,
   выходыRUNR2306. Отсутствие данных не равноSTOP/«аварий нет»/нулю.
2. PV R2302 /100, sourceOKR2303/sourceIndexR2308. SP единая R2100, зеркало
   R2360, семь подтвержденийR2850..2856 — не создавать их дубли, не менять
   RW-свойство зеркала. SP0.10..11.90бар/шаг0.10, pressure-display один знак,
   raw/history без потери точности; scaling только один раз.
3. Все4 F/Q R2500..2503/R2510..2513. Новый I R2504..2507, ×0.1А,
   marker27401/R2509 и движениеНОВОГОR2508. Старый Vfd1CurrentRaw/R2806

   из-за одного неизвестногоQ4.

   65535→65536 иmax4294967295. Существующий корректный DWORDbinding сохранить;
   не создавать8дублей ради word-checker. QПЧ не владеет этой наработкой.
6. Задержки выхода на2/3/4насоса R2123/R2884/R2885, общее снятиеR2124,
   остальные параметрыR2120..2125, ротацияR2140/R2150/R2151 и её единицы.
   Уменьшающиеся/равные выдержки3/4 допустимы. Настройки остаются у ПЛК.

   до3600с; прежний расчёт R2123−R2132 для всех ступеней уже не подходит.
7. CountdownR3120..3125:27402/action/физическая цель/секунды/preset/newHB.

9. Аварийные словаR2550/2551, четыреПЧ, РКФ, подтверждение/снятие/история
   и UTC→МСК без повторного+03. РКФ-памятку/модель CHINT из Бабанова без
   сверки схемы Ошского не копировать. Подтверждение SCADA не равно resetПЧ.
10. Старые readonly-страницы/вкладки/общая диспетчерская и отдельное окно
    используют ту же станцию. Актуальный каталог настроек не выдавать за
    действующую форму ввода, если remote settings так и не были реализованы.

Metadata helper не устанавливает соединений:

python tools/review_oshsky_scada_r3.py

## 3. Проверить поведение без оборудования

Сначала проследить actual Startup/Timer/OnClick и все выходы команд. Если
нужен runtime, отдельная явно помеченная **TEST_ONLY** с внутренними входами/
приёмниками, отключёнными field outputs и отдельным тестовым архивом.
Не писать тестовые значения в рабочие OPC variables/калибратор/БД. Не
подменять лицензию, не запускать конкурирующий OPC writer/радиописатель.
Если native-платформа не допускает изоляцию без переключения работающей
службы, завершить файловый/Compile/доступный тестовый этап и назвать
конкретный неподтверждённый runtime-пункт; общий запрос доступа не повторять.

- Разные F/I всех4:250/270/290/310→25/27/29/31Гц,
  123/456/0/789→12.3/45.6/0/78.9А; отдельный valid0 иraw65535→6553.5А.
- Q4=0приgood1..3, другие3 продолжают работать; наработка4 приgoodPLC
  остаётся. Отсутствие current-feature скрываетI, неF/Q. Неподвижный новый
  heartbeat при движущемся общем, rollback/retainedmarker,65535→0,recovery.
- Пуск разных физических целей при2/3/4ступени, снятие последнего поPLC,
  1/3600/1800с,completion/cancel. Нет собственного HMI/SCADA countdown.
- ПотеряPLC/невернаякарта/контракт, sourceOK0/BAD/stale→fresh, допустимый
  ноль давления. Удобство показывает возраст, а не имитирует живой процесс.
- ReadOnly-индикация сама не пишетPLC. Startup/timer/page/open/reconnect
  не выдают повтор/пуск/reset/Apply. Единственная публикация прежней уставки
  по явному Apply существующего client/user, проверка владельца/контекста/
  concurrentHMI/limits, no retry. EchoR2100/R2360 +отдельное подтверждениеПЧ.
- Если найдена уже действующая remote edit-сессия — STOP/Edit/Apply/Cancel,
  пределы/атомарность/невалидныйshadow. Нельзя включать новую записьactive
  R2884/R2885 в обход shadows/M1464/M1469. В рамках проверки новые control
  протоколы/пусковые возможности не проектировать.
- График: фактический producer, PV/SPbar общая шкала, FHz отдельно,
  native1/6/24ч/курсор/возврат. Invalid→valid иstale→fresh записать в
  отдельный native-архив, показать настоящий разрыв без ложного нуля/
  протянутой последней точки. Reference-model/Archiving=False/одна картинка
  не доказывают gap. Тестировать quality setter/NaN только при поддержке
  этой версии; неизвестное API не выдумывать. Период таймера отдельно от
  archive interval/on-change и от частоты Modbus.

Actual poll/таймер/jitter прочитать/измерить локальным внутренним счётчиком.
HMI3с и прежняя SCADA15с — разные каналы; зафиксировать реальный timeout
каждой feature, не менять его просто ради прохождения сценария.
