## Согласовать фактическую базу без изменения SCADA/ПЛК

1. Найти текущие локальные4-насосные HMI/PLC и проект SCADA10/11 по известным
   папкам/открытым окнам. Не запускать параллельного агента-редактора.
   Сохранить несохранённую HMI отдельно; исходную пару не переписывать.
   Зафиксировать путь/SHA/модель/1024×600/число страниц. Более новые4-насосные
   правки приоритетнее архивного4_37. Не брать3-насосный Бабанов как native-базу.
2. Важный конфликт: C в архивной4_37 ожидает MapVersion31; подтверждённая
   SCADA использовала32. Сверить фактические PLC/HMI/SCADA-чтения/записи,
   прежде всего версию, режим, уставку/зеркало, подтверждения, частоты/качество
   всех4ПЧ, ручные команды/частоты и guards. Подготовить короткую таблицу
   источников/типов/масштабов/разрешений. Не заменять31→32 вслепую и не ослаблять
   проверки карты. Предпочесть существующую согласованную4-насосную базу;
   HMI-адаптацию к действующему контракту делать только по этой сверке.
3. Существующие SCADA/MasterOPC/БД/радио не менять, не перезапускать и не
   активировать другую копию. Снять SHA фактических Project/Pages/Scripts/
   Variables/Servers до и после работ, без публикации содержимого/секретов.
   Не заменять SCADA11 на10 и не переустанавливать старые пакеты.
4. PLC этим этапом не менять. Новый PDW не требуется. Если какого-то показания
   в действующей4-насосной карте нет, не выдумывать адрес/значение: оставить
   честный прочерк и указать конкретный отсутствующий источник. Нельзя для
   этого переносить fixed-three PLC r16 или целиком3-насосный макрос.

## Выполнить перенос

1. В отдельном SK-102CE/1024×600 создать Main в согласованном тёмном стиле:
   четыре равные карточки, крупные показания, прозрачные подписи/цифры,
   голубой разрешённый ввод, белые показания, серый запрет. Уставка крупнее
   частоты ведомых; одинаковые линии/отступы, максимумы помещаются.
2. Все данные/тексты/состояния — native. Чистый PNG хранит только поверхности
   и насосы. Не оставлять запечённые числа, старые слова/серые заплатки,
   наложения статуса и шкалы. Нейтральные дорожки видимы при останове;
   зелёный ротор/заполнение зависят от проверенных собственных данных.
3. В MANUAL на Main четыре группы Пуск/Стоп/частота. Клонировать целиком
   восемь actual4-насосных кнопок и четыре частотных ввода с ручной страницы:
   адреса, тип операции, press/release, инверсия, guards, точность и пределы.
   Четвёртый канал не вычислять по предположению из третьего. «Задать» не нужно.
   Цвет/контур Пуск зелёный, Стоп красный; частоты/Гц крупные, равные по размеру.
   Недоступный числовой NE скрыт, серый readout прозрачен; запреты сохраняются.
4. В AUTO/остальных режимах прежняя сводка ведущего/автосмены; ручной ряд
   показывать только по реальным условиям MANUAL. Источник времени — прежний
   PLC, нового таймера/логики ротации не добавлять. Переключатель режима не
   становится кнопкой HMI. Переход режима/страницы/редактирование частоты
   не должны создавать Пуск. В MANUAL верхняя подпись «Частота ведомых AUTO».
5. Если исходник имеет однократный ручной маршрут LB810→Screen7, изменить
   только его цель на фактический Main, сохранив one-shot/AutomaticReset/
   rearm/приоритет аварий. Ручную страницу сохранить через меню. Не переносить
   переменные/ABI/адреса LocalWord из3-насосной версии без проверки занятости.
   При необходимости новый сервис представления только читает actual-входы,
   пишет свободные local-слова/биты для4каналов; никаких PLC-команд в tick.
6. Нижние6переходов: Насосы/Каскад/Ротация/Ручной/График/Аварии, лёгкие рамки.
   Сохранить actual page IDs и доступность диагностики в служебном разделе.
   Остальным страницам согласовать фон/обычный текст; формы, alarm-таблицы,
   графики, логотип, рецепты и функциональные привязки сохранить.

## Проверить и выдать готовый результат

- Сохранить отдельно `pump_station_4p_scada_main_r1_native.skm` в новой папке
  `_release_private\Станция_4насоса_Main_R1_2026-11-24`. Рабочие копии
  для редактирования нужны; отложена финальная упаковка, не SaveAs результата.
- SaveAs → независимое открытие → ScriptCompile → полныйCompile →
  OfflineSimulator1024×600. Проверить AUTO/MANUAL/СТОП, link/map/busy,
  actual min/max/запреты всех полей. Синтетические адреса только TEST_ONLY.
- Особые случаи: только4-й работает;4-й unknown при живых1–3; каждый из
  восьми Пуск/Стоп даёт press/release только своему локальному приёмнику;
  четыре частоты меняют только свою цель. Без платы/ПЧ не имитировать
  аппаратную приёмку. Ни Download, ни Force/RUN/Apply/полевых записей.
- Сверить защищённые свойства/контракты и SHA SCADA/PLC до/после. Сохранить
  таблицу источников/условий качества4каналов, в т.ч. разрешённое чтение тока.
- Приложить реальные PNG1024×600: AUTO, MANUAL, blocked, максимум,
  четвёртый работает отдельно, неизвестность, final production после reopening.
  Тестовые кадры подписать, не ретушировать и не подменять эскизом.
- Выдать полный Windows-путь, размер/SHA нового SKM, actual4-насосную
  PLC-базу/карту и результаты Compile/Simulator/сохранности SCADA. Обновить
  отчёт/HANDOFF. Новый native/приватные dumps/конфиги в Git не публиковать.
  Если фактический источник/контракт недоступен, завершить независимую
  визуальную часть и назвать ровно недостающий источник; готовность команд
  без проверки привязок не заявлять. Повторного общего разрешения не просить.
