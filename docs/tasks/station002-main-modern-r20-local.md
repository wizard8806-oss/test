## Повторные разрешения CLI

Пользователь сообщил, что r19 ещё работает и постоянно просит подтверждения.
Разрешение не отозвано. Для текущего сеанса `/permissions` позволяет изменить
профиль; выбрать Full Access, если доступен. Для возобновления из той же
папки есть `tools/Start-PumpStation-FullAccess.cmd resume --last`, либо:

```text
codex --sandbox danger-full-access --ask-for-approval never resume --last
```

Это штатные CLI-режимы, не изменение глобального config/WindowsUAC.
SKTool оставить открытым, не запускать второго Codex поверх первого.
После настройки продолжить r19 самостоятельно, затем r20 по этому заданию.
Если вопрос задаёт сам агент, учитывать уже данное согласие; спрашивать
только отсутствующие данные/реальный непреодолимый блокер, а не заново
разрешение на Screenshot/SaveAs/Compile/Simulator. Недоступное действие
описать точно, остальные независимые шаги завершить.
Официальные справки: https://developers.openai.com/codex/cli/slash-commands
и https://developers.openai.com/codex/cli/reference.
