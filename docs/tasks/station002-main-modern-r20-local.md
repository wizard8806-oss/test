# Новый Main «Бабанов»: выбранный тёмный макет №1

Продолжение ПОСЛЕ текущего задания телеметрии r19. Пользователь уже
выбрал направление и разрешил работу: не запрашивать заново общий доступ
и не запускать второго агента параллельно с текущим редактированием HMI.

Эталон и последние уточнения: [спецификация](../ui/station002-main-modern.md),
`docs/ui/assets/station002-main-modern/manifest.json` и три PNG рядом.
Тёмный матовый вариант №1 брать максимально близко. Для2/3насосов7″,
800×480; для4насосов10″,1024×600. Прежние silver/sidebar-эскизы и светлый
вариант не использовать. На месте большого «ПЛК: связь есть» — **Частота
ведомых45.0Гц** (пример). Связь компактно в заголовке. Общая частота
ведомых сохраняет прежнюю привязку Main ND3018/R2110 и его масштаб.

1. Закончи и сохрани native r19 с исправленной телеметрией, запиши путь/SHA
   и actual Open/Compile/Simulator. Для следующего этапа возьми именно этот
   файл. Не откатывайся к старым r17a/r18a и не заменяй нужную открытую копию
   другим одноимённым SKM. Native r19 пока не получена облаком.
2. Сохрани отдельный `pump_station_3p_babanov_r20_main_native.skm`. Первый
   рабочий перенос — текущие3насоса/SK-070HE800×480. Перестрой только Main
   по трёхнасосному PNG; все цифровые значения/состояния/кнопки — native
   контролы, декоративные изображения отдельно. Не подкладывай весь mockup
   с нарисованными показаниями вместо действующих объектов.
3. Сохрани реальные pressure/setpoint/F/Q/I bindings, анимационные выходы,
   свойства чтения и защиту недостоверных данных. F/R2500..2,Q/R2510..12;
   токи нового r19 LW960..962 и их validLW963..965; остальные адреса брать
   из фактического native, не угадывать. Сохрани безопасную модель Variable
   Settings/Batch16 и BootAckW-last, без ручного pVar layout. Main-поле
   частоты ведомых остаётся показанием; не добавляй запись уставки на Main.
4. Строка автосмены должна показывать настоящие данные и фазу, не константу
   из PNG. Найди существующие источники интервала/минут/фазы и корректно
   обработай остановленный отсчёт/выключенную ротацию/ожидание резерва.
   Если требуется дополнительный вход макроса, задай его штатно через
   SKTool с сохранением native ABI; изменение отдельно задокументируй.
5. Сохрани все7маршрутов Main (включая Диагностика→Screen4), общую полосу
   аварий,17страниц/7групп, памятку РКФ и её PNG/автовызов/LB811, ручное
   окно/LB810, логотип/заставку/звук/mute, reset STOP guard и транзакции.
   Программу ПЛК/опрос/пусковые команды ради нового Main не менять.
6. Native Compile скрипта и всего HMI, Save/reopen, Simulator800×480:
   крупные реальные readouts, все переходы, нормальный STOP/RUN/готовность,
   один unknown, потеря общей связи, авария, состояния автосмены. Synthetic
   renderer проверки — только отдельная TEST_ONLY-копия; финальный SKM
   без тестовых значений/подмен данных. Недоступные проверки отметить pending.
7. Дай полный Windows-путь, размеры/SHA нового SKM и внешних assets,
   итоговый C/source-pins, actual Compile errors/warnings и очищенные
   Simulator-снимки native размера. Опубликуй только относящиеся документы
   в handoff; SKM/PDW/JPEG/ZIP/private dumps в Git не добавлять.

Версии2и4 здесь — дизайн-эталоны. Текущий PLC fixed-three не превращать
в двух/четырёхнасосный переносом картинки; рабочие аппаратные варианты
требуют соответствующей проверенной PLC/HMI-карты. Старые комплекты
сохраняются. Загрузку на объект пользователь выполняет сам.
