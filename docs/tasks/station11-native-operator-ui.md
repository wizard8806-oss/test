## 2. Сборка кандидата

После получения актуальной ветки из корня репозитория выполнить:

```powershell
$setupOutput = & powershell -NoProfile -File .\tools\Install-ProjectPython.ps1
if ($LASTEXITCODE -ne 0) { throw 'Project Python setup failed' }
$projectPython = $setupOutput | ConvertFrom-Json
& $projectPython.pythonPath -I -B .\tools\build_native_operator_console_01.py
if ($LASTEXITCODE -ne 0) { throw 'SCADA11 build failed' }
```

Helper использует только официальный Python3.13.17 x64 с закреплённым SHA256
и действительной подписью PSF. Установка для текущего пользователя; PATH/
ассоциации/launcher/pip не включаются, старый Python не удаляется, Windows
не перезагружается. Совместимый подписанный интерпретатор по выбранному пути
повторно не устанавливается. Сохранить возвращённые путь/версию/код и лог
приватно; если подпись/хеш/процесс отклонены, не обходить guard/автопроверку
другим методом, записать точную причину. Не устанавливать Python для всех
пользователей и не менять политики/хранилище корневых сертификатов по гипотезе.
