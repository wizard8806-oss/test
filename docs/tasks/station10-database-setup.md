## 3. Выделить архив и локальную учётку для10

Если собственного пригодного архива10 ещё нет, создать отдельную схему
**`stationtenarchive`** и локальную учётку **`scadaarchive10`** с новым
приватным секретом. Сначала проверить коллизии/принадлежность имён. Если имя
занято неизвестным архивом/учёткой, не очищать/не переименовывать/не сбрасывать:
выбрать свободное отдельное имя и записать причину. Имя схемы — латинские
буквы, согласно [параметрам БД](https://simple-scada.com/help/manual/dbset.html).
План stationninearchive был для09, он не является общей схемой двух проектов.

Администратор создаёт схему; архивная учётка получает необходимые
[права производителя](https://simple-scada.com/help/manual/db-access-rights.html)
на неё: ALTER/CREATE/DROP/INSERT/SELECT/UPDATE, без глобальных прав и GRANT OPTION.
Новое разрешение допускает при реальной необходимости ALL PRIVILEGES только
на выделенную схему и временные пароли; защищённое хранение описано в дополнении.
DROP — только внутри выделенной архивной схемы для штатного хранения; он не
разрешает удалять существующие архивы/таблицы в рамках подготовки. Исключить
его можно при подтверждённом неограниченном хранении обоих архивов; политику
хранения ради этого не менять. Подключение учётки ограничить локальным хостом,
не выдавать `%`/удалённый доступ. Charset/collation не угадывать: использовать
подтверждённый штатный способ производителя/имеющейся версии.
