# HMI-r6: убрать действие кнопки текущего раздела

Пользователь подтвердил последний обычный r5. Новое требование: в открытом
«Ручной» не нужна кнопка повторного открытия «Ручной», аналогично всем
другим разделам. Создай **готовую отдельную r6**: текущий раздел — синяя
плоская статичная подпись без перехода, другие кнопки действуют как прежде.

1. Manifest `artifacts/station002-three-pump-hmi-r6/delivery-manifest.json`
   скачать из того же pinned-коммита, что это задание. Все files[] скачать
   по его rawBase, проверить размер/SHA, сохранить относительные пути.
   Для генерации достаточно Python3stdlib, без GUI/DLL/pip.
2. Новая папка `.worktrees/station002-three-pump-hmi-local-06/` или другая
   доступная без перезаписи. Не создавать worktree ради этой операции.
3. Source: предыдущая готовая local-05 `pump_station_3p_countdown_r5.skm`,
   1254272байта,SHA256
   `1d6449d8884fb9f44e3c6a2c71193d044788d8c2832e884c88e44c0707bdf3a3`.
   Использовать предыдущие отчёты/пути; не запрашивать проект снова.
   Свежие native-save сохранять, guards не ослаблять. При другом SHA
   точный r5 воспроизвести в отдельной подпапке по уже выполненному pinned
   пакету0c27c5e из r4; fallbackManifest указан в новом manifest.
   Пользователь сообщил r5 без отдельного r5_native; если обнаружишь
   неизвестные дополнительные native-правки, их не перезаписывай/не теряй.
4. Выполнить в новой папке:

```text
python tools/build_three_pump_hmi_r6.py --source "ПОЛНЫЙ_ПУТЬ_К_ТОЧНОМУ_R5.skm" --recipe artifacts/station002-three-pump-hmi-r6/navigation-recipe.json --out pump_station_3p_navigation_r6.skm --report hmi-r6-local-build.json
```

5. Проверить1240334байта и SHA256
   `e8c1a0f6ca3684f301728b97f43d481a252cb89cd5b6296ccac8b4f76fce7ade`,
   source unchanged. Генератор меняет14полных records SB→Text, сохраняет
   94других links и scene counts; обновляет directory/back-pointer/EOF.
6. В уже работающем интерактивном SKTool открыть r6 через **File→Open**.
   По последнему отчёту CLI-start SKTool с файлом даёт Tips, а Simulator
   сразу завершается. Не повторять этот способ/поиск/переустановку и не
   завершать чужие окна. Если интерактивного доступа нет, всё равно создать
   готовый SKM, сообщить его абсолютный путь и точный оставшийся шаг пользователю.
7. Доступный Offline Simulator запускать **без связи с реальным шкафом**.
   Шкаф под напряжением, Port0 общий для ПК/HMI; физических действий/
   команд/загрузки PLC/HMI не выполнять ради проверки интерфейса.
