# Создать исправленный HP-r2 локально

## Почему нужна новая копия

Пользователь получил E0 Unrecognized network при F8 первой версии
`station_MC_CM55_900G_24MC_HP_auto_candidate.pdw` (SHA13da2180…c0263).
Она отклонена. Старая инструкция50dd383 воспроизводит именно её и больше
не применяется. Сохранить её для сравнения, не использовать как source.

В r2 исправлены арифметические ветви и длинные условия. Подготовлены37сетей;
27сценариев компонента и38структурных преобразований code→nodes→code PASS.
Это ещё не нативный F8 r2. HMI/N2/3/4 не изменены. Защита: PV>SP+Δ,
Δ2бар по умолчанию; автоматический сброс при достоверном PV≤SP.
Дополнительный исходный предел12бар сохранён.

## Выполнить до готового файла

Пользователь поручил локальную сборку вместо скачивания PDW из чата.
Ничего не загружать в оборудование, не менять рабочие проекты/SCADA,
не публиковать native-файлы. Недоступность GUI не блокирует сборку Python.

Manifest `artifacts/station002-high-pressure-01/delivery-manifest.json`
получить **из того же закреплённого коммита, что и это задание**. В нём
уже указан неизменяемый `rawBase` к исправленному коду. Не брать старый
manifest, не подменять rawBase текущим HEAD/main и не запускать старые helpers.

1. Создать новую доступную папку, например
   `artifacts/station002-high-pressure-local-02`. Существующие файлы сохранить.
   Новый git worktree/git fetch не требуется.
2. Найти точный исходник178400байт/SHA256
   `96686b9948079d700d96e37483063b21de0cbef8f24a3e63785eed5be101abf5`.
   Сначала прочитать `high-pressure-local-build.json` из уже известной
   `.worktrees/station002-high-pressure-local-01/`, если в нём есть путь
   к оригиналу; затем проверить сохранённый там `source-lock` и известную
   папку `candidate-copies/r2860-2879-review`. Ожидаемое имя исходника:
   `station_MC_CM55_900G_2-4_24MC_candidate.pdw`. Проверять SHA, а не имя.
   HP-r1/HP-r2 и старый PLC05 исходником не являются.
3. Скачать восемь `files[]` по `rawBase + path`, сохранив `tools/` в новой
   папке. Сохранить байты без перекодирования и проверить длину/SHA каждого
   по manifest. Python3stdlib достаточно; pip/vendor DLL/редактор не нужны.
4. Из новой папки выполнить установленным Python3:

```text
python tools/build_high_pressure_pdw_candidate.py --source "ПОЛНЫЙ_ПУТЬ_К_ИСХОДНИКУ" --out station_MC_CM55_900G_24MC_HP_auto_candidate_r2.pdw --report high-pressure-local-build-r2.json
```

5. Проверить target179925байт/SHA256
   `7d436bec9fab5a50bd60ae22e269be90a5adfb9a579426b397a7520c82a82db4`,
   `candidateRevision=2`, `insertedNetworks=37`, неизменность source.
   Генератор не перезаписывает имеющиеся файлы; при совпадающем готовом
   r2 проверить его и не создавать лишнюю копию. При несовпадении сохранить
   оба файла под разными именами и сообщить факт, guard не ослаблять.
6. Сообщить пользователю абсолютный Windows-путь к **готовому r2**,
   размер/SHA и путь отчёта. Затем открыть его в WinProLadder и выполнить
   F8, если GUI доступен; иначе явно передать только этот шаг пользователю.
   Не сообщать F8 PASS по результату генератора или облачных проверок.
   Если E0 останется, сохранить полный результат и номера сетей; не удалять
   цепи защиты вслепую. Исходные W85 сравнивать отдельно с baseline.

Если точного source нет, вывести найденные пути/размеры/SHA и назвать
недостающий файл. Не обходить Access Denied, не менять source-lock и
не заменять задачу общим поиском редакторов/проверкой статуса Git.

## Адреса и состояние

Интерфейс HMI R2868..R2879 сохранён. R2880..R2883 — внутренние признаки,
не записывать с HMI/SCADA; R2860..R2867 под будущий N не затронуты.
Полная native-приёмка, HMI и N2/3/4 остаются отдельными этапами.
Подробности: `docs/reports/station002-high-pressure-repair-r2-20261107.md`.

Cloud проверил именно новую доставку:8helpers HTTP200/SHA и запуск Python
`-S` из чистой папки дали точный r2. Повтор отверг перезапись, изменённый
source отвергнут source-lock, оригинал сохранился. Это не наблюдение
Windows-сборки или native F8 r2 у пользователя.
