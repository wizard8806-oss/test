# SCADA11: сохранить верхние вкладки и убрать дублирующую навигацию

03.11.2026 МСК. Пользователь показал активную
**codex_diag_11_layout_20261103t000000z** (БД/40 тегов), проверил динамику
давления калибратором. Затем сдвинул рисунок **в Editor**: перекрывавшиеся
верхние штатные кнопки заработали. Левые кнопки по-прежнему не работают.
Пользователь разрешил оставить верхние — теперь это основная навигация.
Не скрывать панель и не ждать диагностики левого дубликата как условия работы.

1. AGENTS/HANDOFF → Git/местные изменения → актуальные инструменты без потерь.
   **Сначала сохранить ручную правку пользователя в Editor:** если модель
   несохранённая, штатный Save As в новую приватную копию семейства
   codex_diag_11_review_<id>. Проверить ArcSystem.sar/архивные профили/ресурсы:
   если Save As их не перенёс, добавить неизменённые файлы из сохранённого
   исходника после сравнения. Диск до сохранения
   не объявлять равным RAM. Не перезаписывать модель старой сборкой и не
   повторять10→11/БД/радио. Проверить, что сохранённая модель относится к
   указанному layout-кандидату; имя уже известно, повторно не спрашивать.
2. Из текущей сохранённой модели получить аудит Pages/Scripts, SHA, rect/font
   фона/заголовков; сверить с актуальным приватным манифестом. Ручное смещение
   ожидаемо меняет Pages — старый hash998faa4 не применять к этой версии.
   Установить реальные размеры проекта/Client/монитор/DPI/панелей. Повторно
   двигать окно на другой монитор ради диагностики не нужно; графика
   перекрывала кнопки по наблюдению пользователя, а не доказанному сбою GPU.
3. В новой приватной review-копии применить **layout-review --native-navigation**.
   Нужны явные сверенные SHA текущих Pages/Scripts. Режим исправляет FontType16,
   ставит FShowPagesPanel1 (показать) на6 подстраницах и удаляет только29
   дублирующих переходов слева/в диагностике. Остаются102 Text и15 связок.
   Сохраняет координаты/размеры остальных объектов, их UID/права/события/
   подписи, относительный порядок слоёв,48 ID/metadata скриптов/архив/профили.
   В2 модулях применяются только прежние маски одного десятичного знака
   (до10 замен, идемпотентно); остальные46 тел скриптов сохраняются байт-в-байт,
   raw/запись/проверки/журнал остаются прежними.
   Z-order нормализуется после удаления элементов. BOOT/ENTER probe не нужен.

   ```powershell
   # navSource points to the saved operator-modified layout or its reviewed review-copy.
   # navPagesSha/navScriptsSha are its reviewed current digests, not the old source pins.
   $navOut = Join-Path $env:LOCALAPPDATA ('CodexCandidates\SCADA11\codex_diag_11_review_' + [Guid]::NewGuid().ToString('N'))
   & "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" -I -B .\tools\prepare_native_ui_event_probe.py --mode layout-review --project $navSource --out $navOut --expected-pages-sha $navPagesSha --expected-scripts-sha $navScriptsSha --native-navigation
   if ($LASTEXITCODE -ne 0) { throw 'Review copy not prepared; source preserved' }
   ```

   Source-family ограничен подтверждённым layout/review. Если штатный Save As
   имел другое имя, сначала проверить происхождение/состав и адаптировать
   проверку после review; не подставлять иной проект или снимать guards.
   При оставшейся старой диагностике helper отказывает: убрать её отдельно
   после сравнения кода, не выпускать диагностическую версию как конечную.
4. Штатно открыть/Compile All/Save **новую** копию, проверить source/candidate
   и сохранность ресурсов. Этот helper не исправляет координаты: он сохраняет
   ручную правку. В Editor затем довести область до размеров реального canvas,
   выделить место верхней панели/подвалу, убрать случайные серые поля/смещение
   и растянуть нужные фоны. Не масштабировать уже изменённые объекты повторно
   как исходный1440×920 макет. Движение всей картинки — временное восстановление
   доступа, не законченная вёрстка. Изменения воспроизводимо записать в исходники.
5. Штатно загрузить проверяемую копию без двух одновременно управляющих
   проектов. Проверить все верхние вкладки: Все станции/Станция/Диагностика/
   Аварии/Графики/Настройки. Подтвердить отсутствие неработающих левых дубликатов,
   выравнивание, читаемость, один знак после запятой и длинные подписи.
   Отдельное окно/оставшиеся действия и +/−/Отмена проверить отдельно без Apply;
   оставшиеся непроверенными обработчики не считать исправленными автоматически.
6. Сохранить actual Client-кадры обзора/станции против утверждённого макета.
   Верхние штатные вкладки теперь разрешённое отличие; KPI/поиск/фильтры/
   формы/графики и композицию всё ещё нужно довести. Динамика давления принята
   со слов оператора; точность/свежесть/архив отдельной проверкой не подтверждены.
   При препятствии GUI сразу попросить конкретное окно/кадр в чате или через
   уже настроенный Telegram. Если для оставшегося действия нужен probe —
   проверить только его; не начинать снова весь круг диагностики страниц.

Codex сам пишет версии/имя сохранённой модели/SHA/изменения/непроверенное в
отчёт/HANDOFF и публикует согласованные исходники. Включить численные размеры
проекта/Client, DPI, rect фона и высоту панели: эти metadata нужны для
воспроизводимой компоновки и не требуют публикации приватного проекта.
Ручные изменения сохранить.
ПЛК/HMI/радио/командные контракты не менять; при незавершённой приёмке —
штатный возврат проверенной конфигурации с указанием её имени. Private-проекты/
секреты не публиковать; оператор помогает окнами, а не ведением документации.
