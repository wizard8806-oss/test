Это актуальное согласие на переключения ПО и функциональные проверки текущего

ограничения «только чтение/без Apply/пуска/нужно разрешение Stop10» в прежних
задачах — история до этого сообщения. Согласие не является фактом исполнения.

## Выполнить последовательно

1. **Сверить калибратор и подготовить формат.** Выполнить пункты1–3
   [задачи одного знака](station11-calibrator-one-decimal.md): реальные
   PressurePV_x100/PressureSourceOK/MapVersion/счётчик/режим/качество/полное
   время через существующий MasterOPC; сравнение с2,9 до округления. Затем
   чистая display-копия из исходной11, native Compile/Save/сверка. Сотые
   скрываются только на экране; raw x100/журнал/архив сохраняются. Значение
   калибратора не подставлять в тег, source-valid не форсировать.
2. **Проверить навигацию и отображение.** После проверки отсутствия pending
   штатно временно деактивировать выбранный проект10 и активировать ровно
   нужную копию11. Сохранение10 означает сохранность файлов/backup/возврата,
   а не запрет временной деактивации. Не путать её с остановкой насоса.
   При необходимости штатные перезапуски SCADA Server/Client для этого
   опыта тоже входят в разрешение; выбирать фактическое требуемое действие.
   Не запускать одновременно два управляющих проекта одной станции.
   Для probe — подтвердить новый BOOT с её ID, один клик и ENTER/ветки;
   для display-копии — правильный загруженный путь, один знак реальных PV/SP,
   обзор/отдельное окно/черновик и Отмена. Полный план —
   [BOOT/ENTER](station11-live-event-proof.md). Не считать native Compile
   доказательством Server load; диагностическую probe не принимать как готовую11.
3. **Выполнить нужную функциональную проверку стенда.** Начать с фактически
   подключённого насоса и уже существующего штатного пути управления
   (панель/стенд/проверенные команды ПЛК). Перед каждым опытом записать цель,
   исходный режим/SP/PV/частоту/ток/код ПЧ и выбранный путь команды.
   Разрешение есть; если управляющего интерфейса сейчас нет, найти контракт
   по сохранённым проектам, а не угадывать адреса или форсировать внутренние
   M-биты/межблокировки. Недоступность физического селектора/HMI — отдельное
   ограничение конкретного опыта, не причина остановить остальные проверки.
   Провести один короткий пуск → наблюдение фактического состояния/частоты/
   тока/собственного кода ошибки ПЧ → штатный останов. Проверять фактическую
   реакцию, а не только факт нажатия. Не показывать насосы2–4 исправными, если
   их реальные каналы не подключены. Приём уставки и применение ПЧ различать.
4. **При необходимости закрыть подтверждение уставки ПЧ.** Использовать
   [известный контракт](../reports/station10-setpoint-source-audit-20261101.md):
   общий вход HMI/SCADA R2100, зеркало R2360, feedback2850–2856. Проверить
   штатный режим и реальный путь AUTO; в STOP отсутствие drive-ack не считать
   отказом записи. Первую проверку можно выполнить с текущей прочитанной
   уставкой; если нужна новая запись, использовать уже согласованный ориентир
   4,0бар/raw400 в действующем профиле, зафиксировать цель до одного Apply.
   Не спрашивать общее разрешение повторно. Наблюдать новый счётчик, echo,
   feedback/фактическое состояние ПЧ и журнал. Таймаут не вызывает повторный
   Apply/автооткат: сначала разобрать результат. PLC-защиты/пороги/контракт
   подтверждения не снимать ради зелёного индикатора.
5. **Завершить и передать.** По окончании пускового опыта выполнить штатный
   останов проверяемого насоса и записать фактический режим/состояние.
   При незавершённой приёмке11 вернуть рабочую10; сохранить исходные10/11,
   приватные модели/копии и конечный активный путь. Журналы/тренды/периоды/
   числовые шкалы/курсор/вёрстка остаются частью приёмки, где ещё не проверены.
   Архив PV не подключать без корректной исторической маски/свежести.

## Прежний отказ review и фиксация результата

Прошлый Stop10 был отклонён до нового согласия. Теперь предъявлять проверке
точный объект/путь/действие и **новую прямую цитату пользователя выше**;
повторная оценка с новым разрешением не является обходом прежнего отказа.
Не считать изменение документов гарантией допуска инструмента. Если review
снова отклонит конкретное действие, сохранить причину, не обходить его другим
интерфейсом и продолжить независимые части. Отличать отказ review от отказа ПЛК.

показания, каждая команда/цель/время/путь, ответ ПЛК/ПЧ, BOOT/ENTER, итоговая
SCADA/режим насоса и непройденное. Опубликовать только согласованные исходники/
документы; main/частные проекты/секреты не затрагивать. Существующий DPAPI-вход
использовать без вывода пароля. MasterOPC остаётся единственным владельцем
Main50008; радио02/ProgramData/ServiceDiag9336/7000 сохранять, дубликаты

синхронизацию/новую проверку только по push.
