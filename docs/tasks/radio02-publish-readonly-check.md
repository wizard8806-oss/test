# Радио02: установить причину ошибки публикации без нового запуска

Контекст — [снимок/разбор](../reports/radio02-cloud-environment-clarification-20261103.md).
Этот PowerShell использует радиооблако M2M24; среда Codex уже снова отвечает.
Диагностика радио не задерживает выполняемую правку интерфейса.

1. Прочитать AGENTS/HANDOFF/status, сохранить местные изменения. Через штатный
   доступ локального CLI прочитать наличие/SHA установленного Collector02;
   сравнить с89c5762599b6b43044d0688f98f5df4e0d80ac603a70d446ee131351607b0e82.
   Приватные файл/конфигурацию в Git не копировать.
2. Поискать уже работающие процессы Collector02; выводить PID/имя скрипта,
   не полные командные строки. Не запускать новый экземпляр, не останавливать
   процессы, не удалять collector.lock/radio.stop/radio.txt.
3. Прочитать только разрешённые поля stations.json: station/group, server/port,
   выходной каталог/период. Для radio.txt/status/collector.lock снять наличие,
   размер/mtime/атрибуты и доступные сведения о правах, без тестовой записи.
   Если файл занят — записать факт; не обходить блокировку заменой файла.
4. Исходный HResult уже не доступен: пользователь запускал Collector через
   дочерний powershell.exe -File, тот завершился. Попытка агента прочитать
   Error родителя дала NULL/InvokeMethodOnNull; это отдельная диагностическая
   ошибка. Не повторять эту команду/не перезапускать Collector ради Error.
   Если точного исключения больше нет, прямо отметить это ограничение;
   при текущем чтении записывать тип/код только реально полученных ошибок,
   без всей коллекции Error/командных строк/паролей.
5. Если чтение доступно, сравнить run/seq/возраст публикации/выборки радио
   в двух наблюдениях с интервалом больше5000мс; свежий статус старого файла
   не считать сам по себе текущим успехом. Проверить ARADIO1/station/source.
6. По результату назвать установленную стадию: начальный lock, публикация/
   замена файла, права/IO либо пока неизвестно. На снимке RADIO SERVICE/Output
   уже выведены; для сохранённого02 это стадия после начального lock.
   Сетевые статусы/ошибка другого процесса не выводятся из общего catch.
7. Codex сам записывает версию/SHA/UTC/путь, факты и ограничения в отчёт/HANDOFF,
   публикует согласованные документы с сохранением местной UI-работы. Если
   требуется изменение файла/процесса — сначала определить владельца и
   конкретное исправление; данный шаг ограничен чтением, новое радио-окно
   или останов всех PowerShell не являются диагностикой.
