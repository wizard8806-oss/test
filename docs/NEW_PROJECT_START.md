# Передача в новый чат отдельного похожего проекта

28 ноября 2026, МСК. Насосная станция Ошский продолжает собственную задачу.

## Что передать

1. **Обязательно:** `SHARED_CONTEXT.md` из этого каталога — общий опыт,
   требования пользователя, решения, основания и границы применимости.
2. **Для нового объекта, если уже есть:** краткое назначение и отличия,
   список точных моделей/firmware, схема подключения, руководства,
   его исходные native-проекты и сведения о фактически загруженных версиях.
   Убрать секреты из копий до передачи.
3. **По необходимости:** выбранный отчёт/контракт из списка источников,
   если действительно переиспользуется соответствующий протокол или приём.
   Исторический файл передавать как пример с датой и ограничениями.

Старые CURRENT_TASK/HANDOFF, полный AGENTS с историей станции, рабочие
профили связи и секретные хранилища **не нужны как стартовое задание нового
объекта**. Для продолжения Ошского используются его CURRENT_TASK/HANDOFF.
Этот файл можно приложить вторым или просто скопировать сообщение ниже.

## Стартовое сообщение для копирования

```text
Это отдельный проект, похожий на насосную станцию. Прочитай приложенный
SHARED_CONTEXT.md и используй общий опыт и мои рабочие требования.
Адреса, модели, настройки связи, разрешения и результаты старой станции
не считай параметрами или проверками нового объекта.
Сначала установи назначение, отличия, фактическое оборудование и исходники;
пометь подтверждённое, предположения и недостающие сведения.
Создай собственные docs/CURRENT_TASK.md и docs/HANDOFF.md.
До уточнения задачи начни с чтения и инвентаризации.
Текущую насосную станцию, её файлы и работающие процессы сохрани.
```

## Если оба проекта ведутся одновременно

Использовать разные чаты/локальные сеансы и рабочие каталоги/worktree,
отдельные имена native-проектов, манифесты и резервные копии. Общий документ
знаний не заменяет состояние каждого проекта. До работы с общей службой
или каналом определить фактических потребителей; отдельная Git-ветка сама
не изолирует оборудование, MasterOPC, Gateway или учётные записи Windows.
