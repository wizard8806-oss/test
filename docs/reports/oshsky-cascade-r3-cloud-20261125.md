## Готовое поведение

Два независимых preset выхода на3/4насоса R2884/R2885 и отдельные секундные
счётчики. Первая выдержка R2123 сохраняется; новые значения при первом boot
наследуют её, затем редактируются независимо через прежний STOP/Edit/Apply.
Допустимы equal/decreasing1..3600с, невалидный shadow блокирует весь Apply.
Смена кандидата/ступени сбрасывает ожидание, не переносит прошедшее время.

Отдельный PLC Batch R3120..3125 публикует capability/action/физический
номер/остаток/preset/собственный heartbeat. Нет активного ожидания или уже
прошёл commit — action/номер/остаток0. C-компонент скрывает показ при
невалидных данных, STOP/MANUAL, неподвижном heartbeat≥3с; после reconnect
ждёт его движения. Времени на HMI не досчитывает. Маркер и движущийся старый
heartbeat r2 не подтверждают новую функцию после отката.

Прежний R2124/D911 отображается как остановка выбранного последнего ведомого.
Новые отдельные preset снятия **не добавлены**: уточняющий вопрос не отвечен.
Не перенесён быстрый останов из Бабанова; существующие защиты/обычное снятие
сохраняются. При смене цели снятия его elapsed/clock-arm сбрасываются заново.
