# Отдельная PLC-версия для трёх насосов

08.11.2026. Пользователь отложил разбор привычных W85 и указал приоритет:
сделать программу станции с тремя насосами. Работа продолжается от HP-r2,
для которого пользователь показал нативный F8:0 ошибок/25 предупреждений.
Новый трёхнасосный файл требует собственного F8. W85 не исправлялись вслепую.

## Полученный файл

Приватно создан `station_3p_24MC_HP_auto_r1.pdw`,184126 байт,
SHA256 `a6e9c5c057ad324635c10e73b61f25ceb08604c4651eaaf943880f2dc176c745`.
Исходный HP-r2 сохранён, SHA
`7d436bec9fab5a50bd60ae22e269be90a5adfb9a579426b397a7520c82a82db4`.
Имя проекта теперь `PUMP_STATION_3`; CPU остаётся FBs-24MC.
Это фиксированная конфигурация на3насоса. Выбор2/4 с панели не реализуется
этой сборкой; он отложен ради указанного пользователем приоритета.

Генератор source-locked, создаёт новые файлы и не имеет соединения с PLC.
Полные PDW/подробные журналы/дистрибутивы в публичный Git не помещаются.

## Что изменено

- Y1..Y3 сохраняют исходные RUN-условия и общий допуск защиты. Единственная
  катушка RUN Y4 заменена сбросом; ранняя цепь принудительно сбрасывает Y4.
  Даже оставшееся состояние/команда четвёртого слота не включает этот выход.
- Физический READY4, участие AUTO4, связь/давление4, ручной источник4 и
  контроль STOP4 исключены. Подтверждённое участие R723 всегда0; редактор
  параметров принимает только0 для четвёртого черновика. Каскад/ротация
  используют оставшиеся три доступных канала.
- Курсор ручной очереди ограничен1..3. Окончания двух AUTO-очередей перенесены
  с5 на4. Проверки входного/зафиксированного адреса режимов, частоты и PI
  принимают только1..3; четвёртый источник не получает подтверждения связи.
- Основной опрос использует **14 строк**, отфильтрованных по адресу из всей
  исходной чередующейся таблицы, включая позднюю строку частоты ПЧ3.
  Индекс свежего образца частоты ПЧ3 перенесён16→13 (нумерация с0).
- Неизменённые ROM-шаблоны9таблиц сохранены. Нормальный FUN150 переключён
  на RAM-таблицу R2900..R3000: заголовокA550/070E,14строк по7слов и
  сохранённое завершающее слово шаблона. Содержимое задаётся каждый scan
  до работника. Приём с RAM-таблицами уже используется исходными одноразовыми
  работниками; это изменение отдельного параметра существующего FUN150,
  без перестройки его ветвей. Вызовов шаблона R5000 с18строками больше нет.
- Сообщения «ПЧ4 не готов»/«нет связи с ПЧ4» подавлены; аварии ПЧ1..3,
  общие защиты и исходные адреса HMI1..3 сохранены.
- Все37цепей HP-r2 и цепь M221 сохранены побайтно: PV>SP+Δ, начальные2бар,
  автосброс при достоверном PV≤SP, удержание в промежутке, исходный предел12бар.

R2860..R2867 теперь выходной интерфейс фиксированной конфигурации:
N=3, marker27114, draft/display3, status0, mask7, valid1, revision1,
pictureIndex1. Не писать их с HMI как настройки количества.
R2868..R2883 остаются защитой. R2900..R3000 — служебная RAM-таблица,
не операторские параметры. Прямых совпадений операндов и перекрытий таблиц/
R-буферов в принятом source нет; внешние косвенные привязки проверены не полностью.

## Проверено и что остаётся

113 новых сетей/896байт,26точечных изменений существующего code и отдельное
разобранное поле имени проекта.129проверок ограниченного компонента PASS:
фильтрация полного расписания, граничные адреса0/1/2/3/4/5/65535, курсор,
окончания очередей, три физических выхода/запрет Y4, выбор датчика при всех
сочетаниях связи/обрыва1..3, аварии, свежесть частоты3 и регрессия HP.
Это исполнение выбранных участков машинного кода, не полная PLC-симуляция.

113новых сетей прошли vendor code→nodes→code. Из26изменённых интервалов
25преобразуются в обе стороны до/после изменения. Один исходный арифметический
интервал65.G31 уже отклоняется старым DLL с19; в нём меняется только предел
5→4, тот же результат19 сохраняется. Все прочие инструкции/неизвестные
control-слова исходника сохранены, не угаданы и не переписаны.
Независимо проверены PC/метки,9ROM-таблиц, кадр данных, неизменность source
и всех программных байтов за пределами заявленной вставки/26изменений.

Общий `tools/run_checks.py`:51группа PASS в изолированной копии,
исходное дерево не изменено. Генерация из пустой папки Python `-S` с8helpers
дала точный target SHA, повтор отверг перезапись, неверный source отклонён
до создания результата. Публичные helpers будут закреплены отдельным
неизменяемым manifest для локальной доставки; полный PDW не публикуется.

Новый native F8, фактическое исполнение FUN150/обмен с ПЧ, останов/автосброс
и физические выходы пока не наблюдались. В оборудование ничего не загружалось.
SKM не изменён: PLC работает с прежними адресами1..3, оформление панели
под3насоса и поле запаса HP требуют отдельной native-копии HMI.
Доставка — через локальный Python по закреплённому manifest, затем F8.
