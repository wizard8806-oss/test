Впервые есть пользовательское подтверждение основного пути на физической
HMI после bench PLC r3/исправлений HMI r3d. Точная модель панели и установленный
image/build независимо не сверены; отдельные фотографии/срезы регистров
для этой проверки не получены. Не менять этим ранее сохранённые SHA файлов.

Проверка **не включала** изменение/Apply/Cancel новых задержек, прямое
сопоставление маркеров/счётчиков, потерю/возврат связи, вращение при RUN,
четыре физических M900G под нагрузкой или GSM/OPC. Предыдущие проверки
Apply/Cancel на Online Simulator с настоящим PLC сохраняются отдельно.

Анимация остаётся открытым дефектом: пользователь раньше уточнил, что на
объекте вентилятор не вращался при «Работа» и ненулевой частоте. Текущий
СТОП не позволяет проверить такое движение. Следующий этап —
[диагностика и исправление четырёх роторов](../tasks/oshsky-r3d-physical-panel-local-20261126.md),
без силового RUN AC590. Базовые прошедшие шаги не повторять без причины;
при новом HMI-файле выполнить необходимый regression и обновить manifest.
