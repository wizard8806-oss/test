## Проверено по публичному коду

- Current: R2509=27401 и движениеR2508, затем своёQ/значение тока.
- Cascade: R3120=27402 и движениеR3125. Свежесть LB2110 отделена от
  LB2111/2112 активного countdown. Параметры должны читаться в MANUAL/STOP;
  только надпись обратного отсчёта скрыта вне AUTO.
- Фактические `cascade_countdown.c` + `cascade_panel_native.c` временно
  скомпилированы host C с настоящим InfoBCD и stub memory.3проверки PASS:
  STOP/MANUAL сохраняют свежий LB2110, AUTO дополнительно показывает ожидание.
  Это логика адаптера, **не воспроизведение native ABI/batch на панели**.
- В source04 R2329 уже27110. Правильный старый schema/Map32 не доказывает
  наличие новых current/cascade функций. Нельзя по одной схеме объявлять
  программы согласованными или по фото обвинять загрузку/проводку.
