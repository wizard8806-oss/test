## Что ещё нужно выполнить локально

В доступных инструментах нет канала выполнения команд Windows-ноутбука.
Cloud environment готов, VPN/TCP grants не настроены; прямое управление
локальным CLI здесь недоступно. Поэтому **реальная11 на ноутбуке ещё не
создана/открыта/скомпилирована/активирована этим облачным сеансом**.
Локальному CLI передан конкретный воспроизводимый установщик и полный
порядок проверки, а не просьба заново проектировать интерфейс.

Особенности первой нативной версии:

- Каталог на странице настроек пока просматривается; изменение JSON и
  пересборка новой копии — операция наладчика. Форма редактирования каталога
  из Client, фильтры/поиск большого обзора и дополнительные профили — доработки.
- Тренды используют штатную панель. Группы/архивирование/масштаб/качество
  нужно настроить и проверить в кандидате11, исходные Trends/параметры10
  установщик не меняет. Сначала график общей уставки; давление подключать
  только после проверки исторической маски PressureSourceOK/свежести.
  До этого оставлять его неподключённым с явным ограничением, без ложной
  GOOD-нулевой линии. Факт работающего архива сообщений10 этого не доказывает.
- Цвета/масштаб/шрифты и рамка отдельного окна требуют нативного просмотра;
  облачные FPC/Unicorn не заменяют F9 и фактический Client.
- Насосы2–4 неизвестны до подтверждения индивидуальных тегов. Первый насос
  использует прежнюю проверенную диагностику; новые прямые подключения не
  создаются. Команды других станций не подключены.

Предыдущая реальная запись SCADA10 R2100/R2360=400 и её SQL-приём остаются
последним подтверждённым опытом; новых Apply/пусков/режимов здесь0.
