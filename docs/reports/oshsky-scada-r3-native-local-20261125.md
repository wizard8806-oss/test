# Ошский. Проверка сохранённой SCADA под PLC/HMI r3

25 ноября 2026, Windows, МСК. Принято задание `bb5a3ae` в ветке `codex/project-handoff-2026-10-31`. Последующее сравнение интерфейсов `b41f859` учтено при публикации. Simple-Editor 2.6.15.0 завершил «Компилировать все», сохранил отдельный проект через «Сохранить как». Новый процесс Editor открыл его с диска. Получено 7 страниц и 52 скрипта. Для просмотра оставлен один Editor с итоговой страницей «Насосы и каскад».

**Статус для наладчика.** Копия прошла компиляцию и 75 изолированных проверок логики. Проверки Client, архивных разрывов и идентичности шкафа остаются открытыми. Рабочие конфигурации и история сохранены. Команд оборудованию за этот сеанс — 0. [Матрица всех 74 полей](oshsky-scada-r3-bindings-20261125.csv).

## Что найдено на диске

При начале проверки локальные Editor, Server, Client и MasterOPC не выполнялись. Взята сохранённая четырёхнасосная версия с нативным графиком, действующим производителем архивных рядов и формой настроек. В ней сводка использовала первый код ПЧ, у четырёх строк были статические статусы, а диагностический ток первого насоса приходил из старого R2806. Архивный обработчик принимал свежий timestamp за движение ПЛК. Вход частоты имел верхнюю границу 500 raw и отдельное условие, которое пропускало потерю общей свежести.

По конфигурациям прослежена связь от станции SCADA до узла OPC. Соответствие узла отгруженному шкафу требует сверки на месте, поэтому сохранено исходное отображаемое имя станции. Контрольные суммы 328 защищённых файлов сверены после работ. В выборку вошли исходная SCADA, файлы OPC, настройки БД, радио и прежние проекты. Сверка файлов конфигурации не измеряет состояние работающей БД или эфира.

Фактические периоды, паузы и джиттер радио не измерялись. Ранее для PV наблюдалось архивирование по изменению, с нулевым deadband и интервалом проекта. ## Как получены доказательства

- Native Compile All и Save As выполнены в Editor. При независимом открытии проверены сохранённые объекты и связи. [Снимок компилятора](oshsky-scada-r3-local-images/compile-all.png). [Снимок страницы после повторного открытия](oshsky-scada-r3-local-images/pumps-editor.png).
- Тест извлекает из сохранённого файла тела трёх проверенных скриптов. Free Pascal исполняет их с локальными часами, объектами представления, имитацией чтения и счётчиком записей в памяти. Прогон завершился сообщением `PASS isolated Pascal checks: 75`. В проекте, открываемом оператором, тестовых входов нет. Отдельно пройдены 138 случаев проверяющего инструмента метаданных. [Воспроизводимый тест](../../tools/test_oshsky_scada_r3_saved.py).
- Старый статический тест графика останавливается на поиске выражения возраста timestamp. В r3 проверяется движение значения счётчика. Проверка сохранённого обработчика воспроизводит valid/invalid и восстановление в памяти. Ответ архивной БД и линия между соседними точками этим способом не проверяются.
- Для запуска Client инструкция производителя требует локального Server. У имеющегося экземпляра настроено резервирование и общая конфигурация, автозапуск проектов выключен. Отдельный изолированный сервер с тестовым архивом не был доступен. Штатный Server не запускался. На снимке Editor видны исходные прочерки. Снимков работающего Client с показаниями либо разрывом архива в этом сеансе нет.
