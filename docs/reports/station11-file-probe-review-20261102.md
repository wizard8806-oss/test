## Что подготовлено в облаке

`tools/prepare_native_ui_event_probe.py` создаёт отдельную приватную probe
из **дисковой11**, не используя неопределённый Editor-буфер. SHA двух входных
файлов закреплены на последнем локальном отчёте, заголовок2.6.15 и44 связки
проверяются. У неподходящей структуры/скрипта нет обхода guard. Исходники
читаются и сверяются повторно после копирования; файл назначения должен быть
новым, вне исходника и Git. На Windows до копирования устанавливается DACL
owner/SYSTEM; при ошибке ACL данные не копируются. В Linux каталог0700.

Pages/Windows/Variables/Trends/Project/Servers и архив сохраняются побайтово;
старый compiled cache исключён. Меняются только два тела: глобальный
OperatorConsole получает один BOOT на экземпляр модуля, UiOverview0Nav1_OnClick
пишет ENTER/наличие клиента/цели/результат перехода. Все ID/17байт metadata и
остальные46 записей Scripts.ssc сохраняются. Имена клиентов/пользователей
не логируются, тел кода в stdout нет. Private-манифест не публиковать.
Вызов поддерживает `python -I -B`: доверенный соседний parser загружается
явно, без зависимости от PYTHONPATH. Запуска Editor/Server/OPC/БД в helper нет.

`tools/validate_native_ui_event_probe.py` проверяет13 сценариев: копирование,
существующее/вложенное/Git-назначение, изменённые входные файлы, другую версию,
неподходящий ID/тело события/модуля, отказ защиты каталога, изменение источника
во время операции и symlink. Исходники/существующее назначение сохраняются,
остатков stage нет.13 FPC/API-утверждений покрывают однократный BOOT,
ENTER/успех, пустого клиента, отсутствующую цель, общий except и отсутствие
имени клиента в логе. Отдельно проверены изолированный CLI и синтаксис
Windows ACL-кода. Это фикстуры и API-заглушки, не Windows DACL/GUI/runtime.
