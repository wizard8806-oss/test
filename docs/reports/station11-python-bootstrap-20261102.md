## Подготовленный инструмент

`tools/Install-ProjectPython.ps1`, ASCII-источник для Windows PowerShell5.1,
читает `tools/python-windows-package.json`. Устанавливает официальный
обычный Python3.13.17 x64 для текущего пользователя в
LOCALAPPDATA\Programs\Python\Python313. Python выбран из поддерживаемой
ветки3.13; это не утверждение, что он последняя версия всех веток Python.
По умолчанию без изменения PATH/ассоциаций, без launcher/pip/документации/
тестов/Tk; stdlib достаточно для сборки пакета. Совместимый уже установленный
подписанный x64 Python по выбранному пути повторно не устанавливается.

Официальные источники:

- [Страница выпуска3.13.17](https://www.python.org/downloads/release/python-31317/).
- [УстановщикAMD64](https://www.python.org/ftp/python/3.13.17/python-3.13.17-amd64.exe).
- SHA256: `5da012101ba2e17113a9a1cd901e9ce1441086f2b7ecb5de06ec94163899a190`.

В облаке получены страница и файл29941280байт; вычисленный SHA256 совпал
с опубликованным на официальной странице. Из PE/PKCS7 извлечены публичные
метаданные сертификата: O/CN=Python Software Foundation, цепочка Microsoft
Identity Verification. **Доверие Authenticode на Windows в облаке не
оценивалось**: локальный helper отдельно требует Status=Valid/подписантаPSF
перед запуском установщика и затем python.exe. Одного имени издателя без
действительной подписи недостаточно. Проверка TLS/прокси не отключается.

При несовпадении хеша/подписи, неподдерживаемой платформе, занятом каталоге
без совместимого интерпретатора или ошибке runtime установка не продолжается.
Установщик запускается один раз с InstallAllUsers=0/PrependPath=0/
AssociateFiles=0; автоматического повтора, удаления существующего Python или
перезагрузки нет. Код3010 принимается только при успешном последующем probe,
в результате сохраняется рекомендация перезапуска, сам перезапуск не делается.
Probe в изолированном режиме проверяет стабильную версию,64bit, точный путь
и stdlib hashlib/json/pathlib/struct. Выход — JSON с путём/версией/статусом,
без паролей; лог установки остаётся в LOCALAPPDATA\CodexDownloads\ProjectPython.
