## Ошибка в предыдущей правке шрифта

В998faa4 FontType11 был ошибочно принят за ftRegular18 по порядку таблицы
справки. Из настоящей RTTI закреплённого Editor2.6.15 (SHA c90b3e89…2078b57)
прочитаны26 значений:4=ftMedium15,11=ftAsOwner,16=ftRegular18. Исправлен
FONT_REGULAR18=16 и проверка ordinal каждого выходного объекта. Старый

ровно FontType, сохраняя rect/подписи/события/права/прочие байты.

## Штатные вкладки и навигация

Руководство2.6.15 «Замена штатного интерфейса» прямо предусматривает скрытие
панели страниц и собственные кнопки. Native RTTI FShowPagesPanel находится
в offset0x13c подстраницы. Loader129bd75 читает этот Byte, getter129c28c
даёт0=наследовать,1=показать,2=скрыть. Независимое исполнение loader/getter
в изоляции проверяет6 сочетаний с родительским состоянием. Это не GUI.
После нового выбора пользователя реализован режим **показать** панель
на всех6 подстраницах; код скрытия в текущую поставку не включён.

Текущий UiGoPage(Page,Client) совпадает с официальным API, но молча выходит
при пустом Client/nil цели. Статика не определяет фактический вызов OnClick/
пользователя/пустое имя/перекрытие/скомпилированную runtime-привязку. Причина
не заявлена установленной, права/таймауты/адреса не менялись по гипотезе.
Для оставшегося неисправного действия возможен точечный probe. Дублирующее
левое меню по новому плану удаляется, его диагностика больше не блокирует UI.

Новый file-only mode layout-review принимает явные сверенные Pages/Scripts
SHA текущего кандидата/review-family; копирует приватно с сохранением архива/
ресурсов. Опционально добавляет прежний read-only probe в2 скриптах, без смены
их ID/metadata. Основной режим **--native-navigation** оставляет верхние
вкладки, удаляет только29 боковых/диагностических переходов:131→102 Text,
44→15 связок. Все48 ID/metadata и оставшиеся UID/события/права/тексты/
координаты сохраняются.46 тел скриптов неизменны, в2 модулях — только до10
старых проверенных масок одного знака (идемпотентно), raw/журнал/команды прежние.
Z-order нормализуется без изменения относительного
порядка. Флаг несовместим с probe, отвергает неудалённую диагностику; уже
удалённую кнопку нельзя использовать как probe-target. Преобразование
идемпотентно. Старый preparation-манифест заменён новым, не включён
в собственный candidateSHA. Новое audit-поле layoutControls раскрывает лишь
имена стандартных контролов/rect/font, без заголовков/тел скриптов/секретов.
