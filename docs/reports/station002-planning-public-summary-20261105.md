для каждого ПЧ. Подготовлена оценка изменений PLC/HMI/SCADA/радиодиагностики;
подробные материалы оставлены вне публичного Git. Это планирование, новые
PDW/SKM/теги не создавались, рабочие файлы/оборудование не менялись.
Текущая задача локального CLI по качеству графика сохраняется; новая станция
не является поручением прервать её или применить конфигурацию сейчас.
