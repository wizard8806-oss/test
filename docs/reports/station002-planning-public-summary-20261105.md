# Краткий контекст подготовки дополнительной станции

Пользователь уточнил: готовится дополнительная станция, существующая остаётся.
Целевая комплектация — FBs-24MCR2-AC с CM55, SK070HE, три 900G с тремя
отдельными датчиками давления, отдельный TELEOFIS/M2M24, без сирены.

Чтение опубликованного PLC-исходника подтвердило отдельные каналы давления
для каждого ПЧ. Подготовлена оценка изменений PLC/HMI/SCADA/радиодиагностики;
подробные материалы оставлены вне публичного Git. Это планирование, новые
PDW/SKM/теги не создавались, рабочие файлы/оборудование не менялись.
Текущая задача локального CLI по качеству графика сохраняется; новая станция
не является поручением прервать её или применить конфигурацию сейчас.

Последнее требование — единый проект для станций с 2–4 насосами. Установленное
количество выбирается на HMI и хранится в ПЛК; для новой станции это 3.
Фиксированные версии алгоритма по количеству не планируются. Состав AUTO —
отдельный параметр. SCADA должна читать подтверждённую конфигурацию узла.
