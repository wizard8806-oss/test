## Почему runtime-опыт остановлен

Editor открыт на `codex_diag_11`, в Script Editor с выбранным
`OperatorConsole`. Доступное дерево Windows UI Automation не публикует
дочерние редакторские контролы. Синтетический ввод не позволил надёжно
подтвердить адресата и прочитать текст текущего буфера. После навигационных
попыток у `OperatorConsole` отображается звёздочка несохранённого состояния.
Save, Compile All и перезапуск Server не выполнялись; Editor оставлен открытым.
Поэтому нельзя утверждать, что in-memory-буфер совпадает с диском, хотя
дисковые SHA обеих контрольных частей совпадают с pre-test-копией.

Уникальный BOOT/ENTER ID не был установлен: логирование и клик не выполнялись.
Не следует считать текущий журнал свидетельством доставки события или
делать вывод о причинах навигационного отказа. Для продолжения нужен
надёжный штатный ввод текста/сохранение/Compile All в Editor с контролем
видимой привязки; затем следовать неизменённому заданию, дождаться новой
BOOT-метки и только после неё выполнить один диагностический клик.

Приватный backup и журнал остаются вне Git. Существующие два station09
JSONL не изменялись. Новых установок и проверок MySQL не было.
