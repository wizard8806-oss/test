## Дополнение: откат выбора в GUI и более новая native-копия

Оператор предпочёл ручное исправление, затем сообщил об откате на1 после
OK/повторного открытия. Кадры показывают3/Screen4 в ещё открытой форме;
сохранение этой цели не установлено. Пользователь запросил задание локальному.

Добавлен режим **--source-sha256** для actual native-файла после попыток.
Вместо подмены на старый source локальный измеряет SHA текущей копии,
запускает ограниченную проверку модели/16страниц/7групп/известного C-macro SHA
и нормализует только пять целевых полей SB6010. Все остальные байты
сохраняются полной инверсией. Исходный befe даёт прежний exact-output4dba.
Для несогласованного/откатившегося маршрута поддержаны текущие значения
в пределах16экранов; alreadyCorrect сохраняет файл побайтно.

Проверены: отказ новому source без пина и неверному пину, сохранение новой
пользовательской подписи при исправлении маршрута, идемпотентность, смешанные
значения полей и отказ изменённому макросу. Пакет8файлов описан в новом
delivery-manifest. Нативная проверка ещё ожидается; повторяющийся откат нужно
фиксировать сравнением полей/файлов до и после Save/Compile.
