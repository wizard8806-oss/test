## Следующее наблюдение пользователя: новый журнал виден в редакторе

Пользователь нашёл штатный элемент **Tool Box → Function elements → Display →
History Alarm**. Его диалог называется `Historical alarm display`, новый ID
`HAD1794244624`. Меню `Draw(H)` на установленной версии содержит примитивы.
В General показаны Reverse, Rows6, два шрифта10, включённые Time D, Data D
и Select all alarm content; выключенные Clear Alarm Date/Time. Заголовки
«Время», «Дата», «События» введены в текущем языке Chinese. Вкладка Visibility:
By Bit/User Level, Permission, Logic и Word control выключены. На втором
снимке Text Color ещё чёрный; пользователь получил инструкцию выбрать
красный для активного текста. Подтверждения окончательного цвета пока нет.

Последний снимок показывает размещённую новую таблицу с заголовком и шестью
строками в **редакторе** Screen9. Она помещается между верхними кнопками и
нижней статусной полосой, навигация свободна. Title всё ещё содержит
`pump_station_3p_alarm_rebuild_r12_base.skm`; это не доказательство отдельного
SaveAs либо состояния сохранения текущего буфера. Текущий дисковый SHA
не читался, исходный SHA диагностической основы нельзя приписывать новой
редакции после пользовательских правок.

Следующий шаг: сохранить рядом **pump_station_3p_alarm_r12_native.skm**, заново
открыть именно его и Screen9, затем проверить Offline Simulator/Compile.
Не регенерировать основу поверх текущих правок и не возвращать HAD8288.
Ещё не подтверждены повторное открытие, Simulator с новым элементом,
две длинные записи/их цвет/прокрутка и работа «Сохранить журнал». Макросы,
определения аварий, каскад8 и PLC этим ручным добавлением менять не поручалось.
Оборудование/Download/Force/RUN агентом не затрагивались. Облачная база
при приёме наблюдения — `83bb77dc89a0d2a83b431cf10eaf167ba631278f`.

открытия страницы редактора и её отрисовки в Simulator без старого HAD8288.
Внутренний механизм прежнего зависания не установлен. Таблицы в основе
намеренно нет; её отсутствие не является новым отказом.

Следующий шаг — создать **новый** `Historical alarm Display` / `History Alarm`
штатным SKTool, используя существующие определения аварий. Точный путь меню

открытого `Draw(N)` после закрытия только текущего Simulator. Старая справка
называет Tool/Toolbar, а перевод различает обычный Alarm Display и журнал;

сетки/двух длинных сообщений. Эти проверки и создание нового HAD пока
не выполнены. PLC/аппаратные команды не менялись.
