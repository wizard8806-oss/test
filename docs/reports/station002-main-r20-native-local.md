## Границы результата

Это завершённый offline-перенос интерфейса. Синтетический renderer не доказывает
Modbus/тайминги/полевые сигналы. Новое настоящее аварийное событие в Alarm Display
и новый power-fault edge/автовызов РКФ здесь не инъецировались; их сохранённые
исходные настройки/код не выданы за новое аппаратное подтверждение.
Обмен на панели, доставка аварии и реальные пуски проверяются отдельно.
PLC/радио/SCADA10/11 в этом этапе не менялись и не переизмерялись.
Варианты2/4насоса остаются дизайн-образцами; готовой аппаратной карты для них
этот перенос не создаёт. Новые native-файлы и приватные helpers в Git не включены.
