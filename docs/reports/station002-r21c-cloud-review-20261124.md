# r21c: облачная сверка ручного экрана с целевым рисунком

24.11.2026. Получен локальный коммит
`1670a0e2b4ee40fe228fb958d3f62f78d4fb4722` и прочитан
[отчёт native r21c](station002-r21c-native-local.md). Осмотрены прямые PNG
MANUAL, blocked, minimum/maximum, AUTO, production и полный Compile.
Проверка проводится по опубликованным изображениям; Windows/SKTool и сам
приватный SKM из Cloud не запускались и побайтово не читались.

## Результат по пяти замечаниям

| Замечание к r21b | Наблюдение в r21c |
|---|---|
| Серые Пуск/Стоп | Зелёные/красные подписи и тонкие контуры; общий размер кнопок сохранён |
| Мелкие ручные частоты | Цифры увеличены, голубые при разрешении и серые при запрете; единицы нейтральные, без индивидуальных плашек |
| Серые накладки под шкалами | Заменены поверхностью в палитре карточек; подписи/деления читаются одним слоем |
| Нет пустых дорожек у остановленных | Дорожки видны у всех трёх насосов; у остановленных 2/3 зелёного заполнения нет |
| Пропало AUTO в ручной подписи | «Частота ведомых AUTO» восстановлена в MANUAL; в AUTO подпись без суффикса |

Эти пять пунктов прошлого задания визуально исправлены. В MANUAL одна
работающая помпа, один зелёный вентилятор и счётчик1 согласованы; в AUTO
две работающие, два зелёных вентилятора и счётчик2 согласованы. Достоверный
останов отображается0.0, production без связи показывает прочерки у измерений.
Чистые тестовые PNG являются снимками TEST_ONLY с локальными входами;
их отсутствие raw-полосы не превращает их в аппаратное доказательство.

Стилистика остаётся приближением эскиза: у native-кнопок прямые углы,
у рисунка скруглённые; нижняя навигация и общие поверхности более однотонные.
Полное пиксельное совпадение с генерированным рисунком не утверждается.
Новых наложений текста на осмотренных кадрах не обнаружено.

## Независимые измерения ручных полей

В `manual-max.png` все три значения50.0 имеют точный цвет #8ED8FF.
В `manual-blocked.png` те же значения #B1BEC6 занимают те же координаты:

| Поле | X цифр | Y цифр | X единицы «Гц» | Зазор до единицы |
|---|---|---|---|---|
| Насос1 |182..230|356..375|237..254|6 пустых столбцов|
| Насос2 |446..494|356..375|501..518|6 пустых столбцов|
| Насос3 |710..758|356..375|765..782|6 пустых столбцов|

Видимая высота цифр20px вместо13px в r21b. У единиц y363..375: общая
нижняя линия375. Между каналами ровно264px, активная/запрещённая геометрия
не меняется. Maximum/minimum помещаются, все единицы остаются внутри800px.
Прямоугольники объектов частично пересекаются, но реальные глифы не наложены.

## Проверки и актуальная база

На полном Compile PNG читаются «The project was compiled successfully»
и «Finished to compile!», Download0%. Локальный отчёт даёт Script0/0,
SaveAs/reopen/Simulator, клавиатуры/границы/guards, шесть тестовых приёмников63
и запрещённые Пуск0. Эти действия выполнены локальным агентом; Cloud их
не воспроизводило и не проверяло физические контакты/приводы.

Для дальнейших правок использовать готовую r21c:
`pump_station_3p_babanov_r21c_main_manual_native.skm`,1650072байт,
SHA256 `9ba1a287f70df1167b2bc927b9d059d0b02372b147e6b083756c251e589fec0d`.
Полный Windows-путь — в локальном отчёте. C/PLC/разрешения сохранены по
его приватному аудиту. Реальная телеметрия/ток/RS485 и аппаратные блокировки
остаются отдельной проверкой стенда. В этом проходе Cloud изменило только
документы/текущую ссылку на базу; новый native не создавался.
