# Наблюдение памяти исходного насосного проекта

07.11.2026, последовательные пользовательские снимки WinProLadder.
Пользователь открыл восстановленную насосную PLC05; в дереве проекта
показана модель **FBs-32MC**.

| Штатное окно | Наблюдение |
| --- | --- |
| System Configuration → Memory Allocation | Retentive Data Register Totals=3000; R0..R2999 |
| Tool → Element Statistics (F7), тип R, все адреса | R2860..R2879 полностью видны без отметок использования |
| Соседние адреса на предыдущем снимке | R2854..R2856 имеют отметки; проверка выполнена не по пустому списку всех адресов |

Таким образом, предложенный блок входит в настроенную retentive-область
исходника и не отмечен его штатной статистикой как используемый. Это
дополняет read-only workpack, в котором отсутствуют совпадения стандартных
операндов блока и перекрытия с сохранёнными таблицами/их R-буферами.

Наблюдение не доказывает отсутствие обращений во внешних проектах или
произвольной косвенной адресации. Не выполнены power-cycle, проверка
реального контроллера, перенос на24MCR, F8 или исполнение нового N.
Полные снимки с посторонними окнами и private native-файлы не опубликованы.

Продолжение: [создание отдельных PLC/HMI-копий](../tasks/station002-pump-count-implementation.md).
Повторять эту проверку исходника без новых изменений не требуется.
Настройки CPU/retentive проверить на целевой копии FBs-24MCR2-AC после
переноса. Результат локальному нужен в native-файлах; reference/HTML-прототип
остаётся отдельным предварительным результатом.
