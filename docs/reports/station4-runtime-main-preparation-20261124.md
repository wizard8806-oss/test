# Наработка на главном экране4насосов: источники и подготовка

24.11.2026 пользователь добавил к текущему переносу4-насосной HMI:
«давай попробуем ещё добавить индикацию наработки на главный экран».
Изменение включено в прежнее задание, не в отдельный повтор переноса.

## Существующие источники

Read-only разобраны объекты архивной HMI
`source/hmi/pump_station_4_37.skm`, SHA256
`13cc9f7d1c5fa59d25c0eb871a2deb3e6f1ef6ca5079be2f5828df5f9e8f5867`.
Объекты ND14004/14008/14012/14016 имеют по200строк свойств и читают
R2200/R2202/R2204/R2206 соответственно. У всех одинаковая gain-строка
0.166666666666666666 и исходные параметры52..55:9/1/2/1. Это сохранённые
параметры, не самостоятельно подтверждённая расшифровка всех enum native.
На странице есть подпись «Наработка, ч» и пояснение о времени команды RUN.

Раздельно прочитан PLC04, SHA256
`a25f9b5d2fe006bcb039896bae3989569b08e1b1adc4b503a755bfd5e3b22993`.
В60.01A/B есть копия минутного такта и его импульс, в60.02..05 — отдельные
накопители с базами R2200/2202/2204/2206. Для будущего показа нужны полные
пары слов, без обрезки до16бит. Счётчик определяется исходной командой RUN;
это не новая оценка фактического вращения двигателя.

Данные/static-метаданные: `assets/hmi/main-four-scada-r1/runtime-source-evidence.json`.
Текущая Windows4-пара, её native-типы/порядок слов/перевод в часы сверяются
локально до клонирования. Время аппаратного такта и реальное накопление
в Cloud не измерялись; контроллер/SCADA не менялись.

## Подготовлено

В каждой карточке строка «Наработка … ч» под током, над статусом/шкалой.
Белое read-only число с одним десятичным разрядом, прозрачность, одинаковые
отступы. Видно во всех режимах. Ноль отличён от неизвестности. Источник
валидности — чтение PLC-счётчика, а не F/Q ПЧ: при неизвестной частоте
отдельного ПЧ его накопитель в здоровом ПЛК может оставаться достоверным.

Обновлены AUTO/MANUALэскизы и чистый фон, продлённый вниз под новую строку.
Все изображения сгенерированы image_gen; это не Simulator-доказательства.
Нативные карточки теперь128..422, общий ряд430..478, аварии486..528,
навигация536..584, между нижними рядами8px. Основные показания и размеры
ручных кнопок сохранены; все4счётчика и12ручных целей внутри1024×600.

Обновлены [spec](../ui/station4-scada-main-r1.md),
[то же задание](../tasks/station4-scada-main-r1-local.md), DESIGN/HANDOFF,
layout-4.json и SHAmanifest. Зафиксированы обязательные native-пробы:
0/60/120raw, четыре разных значения,65536/high-word,выше2^31/верхняя
32битная граница, совпадение страницы «Насосы» с Main, неизвестность PLC
и отдельная неизвестность F/Q при достоверном PLC-counter.

## Границы результата

Проверены исходные SHA, поля ND, корректность новых PNG/manifest, геометрия
счётчиков/ручных целей и ссылки. Рабочих native-байтов4из Windows Cloud не
получало; реализация на панели, native-преобразование/округление и фактические
min/max-дисплеи ещё не проверены. Ни новый PLC-таймер, ни запись/обнуление
R2200..R2207, ни SCADA-теги/скрипты не создавались. Итоговый SKM дорабатывает
локальный в текущей r1; уже выданную r1 сохраняет и при необходимости выпускает r2.
