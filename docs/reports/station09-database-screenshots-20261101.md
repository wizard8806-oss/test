## Источники и установленные факты

Прочитан [локальный отчёт](station09-write-diagnostics-20261031T204851Z.md).
Он не получил архив AddMessage или OPC-результат попытки 4.0 бар.
Доступный MasterOPC Server.log начинается после опыта; runtime-логи SCADA
не подтверждены как архив сообщений. Исходный отчёт не изменён.

Затем пользователь показал два изображения:

1. Client → «Все сообщения»: «Сервер не подключен к БД! Настройте подключение
   к БД в меню Проект → Настройки → База данных».
2. «Настройки → База данных»: архивирование v2, MySQL, localhost:3306,
   пользователь root, пустое имя базы. В поле пароля символы не видны;
   наличие/значение сохранённого секрета не установлено и не извлекалось.

Просьба открыть список выполнена; прежнее ограничение foreground больше не
объясняет недоступность архива. Подтверждено DB_NOT_CONNECTED в показанном
Client и незаполненное имя базы в показанной форме. Снимки не подтверждают
установленный MySQL, сохранение формы, активный каталог проекта или состояние
БД в момент прежнего опыта. Пароль Client не является паролем SQL автоматически.

Руководство производителя поясняет [роль БД для архивирования](https://simple-scada.com/help/manual/database.html)
и [поля статуса в Server](https://simple-scada.com/help/manual/server-database.html).
В сохранённом исходнике StationDiagnostics вызов AddMessage предшествует
единственной записи Command.Value, но устойчивое сохранение сообщения
отдельно не проверяется. Возврат AddMessage без исключения не доказывает
наличие архивной записи при отсутствии подключения БД.

## Ограничения и следующий шаг

Отсутствие архива сейчас не устанавливает причину отсутствия эха R2100/R2360.
Подключение БД не обещает исправить таймаут или восстановить несохранённую
историю. Доставка raw400/результат OPC и активный путь09 остаются неизвестны.

Подготовлено [задание локальному CLI](../tasks/station09-database-preparation.md):
прочитать существующие компоненты, службы и локальные слушающие порты,
начиная с MySQL, доступные несекретные параметры и подготовить конкретный план.
Облако не имеет прямого канала к ноутбуку. Проверка установки Windows ещё
не выполнена. Новых подключений БД/Apply, установки, запуска служб,
сохранения настроек, правок рабочих проектов или команд оборудованию нет.
PowerShell-радиосборщик, ПЛК и HMI сохранены без изменений.

Передача содержит только этот отчёт, AGENTS/HANDOFF и два задания. Проверки
состава, ссылок, секретов и сохранности остальных файлов фиксируются в HANDOFF;
полный runtime-runner не повторяется для документации. Финальный SHA передачи
проверяется в origin отдельно от базового SHA, указанного выше.
