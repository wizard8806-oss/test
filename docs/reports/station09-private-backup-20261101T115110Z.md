## Штатный способ для отдельного последующего задания

В ранее просмотренном нативном меню2.6.15.0 есть «Проект → Сохранить как…».
[Руководство производителя](https://simple-scada.com/help/manual/menu-project.html)
определяет его как сохранение текущего проекта под новым именем. Это штатный
способ сериализовать текущую редактируемую модель в отдельный проект; не
сохранять исходный09 и не выбирать существующий проект для перезаписи.
Процедура здесь **только установлена по документации, не выполнялась**;
формат/состав фактически полученной копии и сохранение всего внутреннего
UI/undo-состояния не проверены и не обещаются.

План для отдельного разрешения:

1. В оставленном Editor сохранить текущий редактируемый проект через
   «Сохранить как…» под новым уникальным именем, например
   `codex_diag_09_editor_unsaved_20261101_<время>`, без перезаписи09.
   Проверить фактическое назначение в штатном диалоге. Возможность указать
   произвольный путь вне Projects в2.6.15.0 не установлена: если разрешено
   только имя, появление отдельной подпапки Projects также требует задания.
2. До подтверждения учесть текущий режим «сохранить и скомпилировать».
   [Руководство общих настроек](https://simple-scada.com/help/manual/genset.html)
   различает сохранение с компиляцией и без неё. Поведение «Сохранить как»
   именно в2.6.15.0 без компиляции ещё не проверено; молча считать его
   нейтральным экспортом нельзя. Переключать режим сейчас не разрешено.
3. После разрешённого сохранения проверить отдельный путь/состав, составить
   второй приватный SHA256-манифест; повторно доказать неизменность исходной09.
   Не запускать/активировать созданную копию, не возвращать Editor на исходный
   проект автоматически. Новый проект и его файлы оставить вне Git.
