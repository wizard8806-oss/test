## Частота, ток и собственный код

До изменения ПЛК за 110,23 с получен 171 разнесённый по времени цикл чтения. Зафиксировано 33 перехода R2510 в обе стороны. Между наблюдаемыми восстановлениями качества 5,846–7,025 с, медиана 6,779 с при выдержке 5 с. Реле и датчик давления, по сообщению пользователя, отключены. Чтение семи слов и их качество не зависели от этих входов.

В r3g четыре собственных семисловных снимка и четыре штатных чтения давления остаются в каждом обходе. Пока есть недоступные адреса, контроллер чередует пять пар вспомогательных чтений. При четырёх доступных приводах действует полный цикл из 18 исходных операций. Нового запроса ошибки нет. Регистр R3610 подтверждает версию, R3611 — heartbeat, R3612…3615 — четыре принятых кода, R3616…3619 — качество, R3620…3623 — время ответов, R3624…3627 — номера снимков.
