## Дополнительная неоднозначность Access

В224 строках команды с правильными именем иPDU типы постоянны uint32/uint16,
но поле Access:219 ReadWrite и **5 ReadOnly**, seq6/11/80/122/210.
Производный файл эти метаданные не содержит; сведения получены из первичных
описаний. По одному этому полю нельзя заключить, что право действительно
переключалось: есть другие ошибки/смешанные поля MSAA. Это новая причина
сверить действующее свойство/результат записи другим доступным источником,
**не основание автоматически менять права или тип**.

Серия счётчика без изменения попала в общий интервал наблюдения; точное время
нажатия неизвестно, причинная связь с командой не доказана. Просто увеличить
таймаут на этой основе нельзя:400 не видно и в более поздних выборках.
