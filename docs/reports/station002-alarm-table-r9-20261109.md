## Параллельный вопрос об AUTO

Пользователь подключил калибратор к первому насосу, но AUTO не запускается
с «Неверная частота ведомых». Это штатный guardR2110 вне200..500 (20..50Гц).
Ручные25Гц относятся кR2180..2182 и не задаютR2110. Менять guard/записывать
за пользователя произвольную частоту нельзя.

Первоначально ошибочно предложено искать поле в «Каскад». Пользователь
показал «Настройки каскада»: там шесть других параметров, этого поля нет.
В точном r8 поле NE5004 boundR2110 находится **на основном экране
«Станция», слева**, input limits200/500, одна дробная цифра. Пользователь
подтвердил: значение было0, после изменения AUTO заработал. Дополнительная
правка guard для этого не нужна. r9 теперь является промежуточной HMI для
каскадной r10; проверка нативной сетки остаётся обязательной в конечной r10.

Следующий шаг — локально создать отдельную r9, открыть через File→Open,
Compile и Offline Simulator. Требование приёмки: рамка/все заголовки/сетка
таблицы видны даже без связи и при0аварий, сообщение помещается по ширине.
Ни source-hash, ни отсутствие ошибок Compile это наблюдение не заменяют.
Если интерактивный GUI недоступен, готовый SKM всё равно создать и указать
конкретный оставшийся осмотр. В оборудование автоматически не загружать.
