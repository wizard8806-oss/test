## Причины и исправления

1. Исходная программа на стенде давала общую карту и heartbeat без двух экспортов более новой r3. Загрузка совместимой r3 воспроизвела продвижение всех трёх источников.
2. Даже с исправным экспортом в Online Simulator диагностическая r3a читала напрямую 27401 / 27402 / 27110, а макрос показывал 1 / 0 / 0. Значение 27401 попадало в поле heartbeat. Для трёх однорегистровых чтений макроса (R2554, R2329, R2300) в исправленной HMI применены штатные однозначные пакеты Batch UInt16, Bytes=2. Контракт и режим берутся из элемента 0. Карта, как и ранее, берётся из AlarmWords[4]. У BootAck сохранены одиночный тип, направление W и адрес R2553. Всего семь настроек переменных.
3. После исправления раскладки отдельная проверка на странице Каскад выявила ещё одну причину. При валидном RTC, контракте 27110 и маркере 27402 макрос видел застывший R3125=0. На странице с прямым опросом R3125 счётчик двигался. В r3d на Main, Каскаде и двух диагностических страницах добавлены недостающие native Numeric Display только для чтения используемых адресов R2504..2513, R3120..3125, R2300, R2329, R2554. Служебные объекты размером 1×1 принимают данные на активной странице. Прежние макросы вычисляют возраст, качество и состояние. В проверке сохранились порог 3 секунды, независимое Q каждого ПЧ и реальные блокировки ввода.
4. MD5070 теперь подтверждает последнюю операцию. При LB2110=0 независимо видна строка о неподтверждённых выдержках 3/4. Остальные сообщения PLC и транзакции сохранены.
5. Диагностика → «Экспорты» (ID14) и «Токи / режимы» (ID15) показывает прямые слова и снимок макроса. LW54100 — номер снимка, 54101..54106 — маркеры, счётчики, контракт и карта, 54110..54115 — декодированный RTC, 54116 — валидность RTC, 54117 — возраст каскада (65535 при недоступности), 54118/19 — причина закрытия допуска каскада/токов, 54120..54127 — четыре исходных тока и четыре Q. Для проверки сфотографировать «Экспорты» дважды через 2–3 с и затем «Токи / режимы». Прямые поля обновляются асинхронно, допустима разница на один отсчёт на кадре.
