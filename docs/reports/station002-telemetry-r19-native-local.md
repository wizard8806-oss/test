## Что остаётся

Offline-этап завершён. Не подтверждены реальные HMI↔PLC↔ПЧ, свежесть/тайминги
serial на стенде, ненулевой ток под нагрузкой и доставка полевого события.
Host115C/57общих групп из облачного предшествующего отчёта здесь повторно
не запускались: отсутствует подходящий Linux cc. Они не названы Windows PASS.

Далее пользователь подключает отдельный стенд с одним ПЧ по штатным RS485
параметрам, без конкурирующего master. По очереди slave1/2/3: сравнить
F/I/markers с дисплеем, для отсутствующих адресов ожидать unknown;
проверить собственный timeout/recovery и READY/RUN по реальным сигналам.
Без двигателя проверить0.0А; ненулевой ток требует нагрузки. Измерить период
собственного обновления и таймауты отсутствующих slave. Ошибка другого запроса
при свежем собственном снимке требует отдельного воспроизведения и не доказана
самим отсутствием двух ПЧ. Watchdog не увеличивать. Подробный протокол:
`docs/tasks/station002-telemetry-r19-bench-local.md`, раздел4.

Документы/исправление builder и очищенные Simulator-снимки публикуются
в `codex/project-handoff-2026-10-31`; native/копии/RAM/assets/локальные helpers
остаются на этом PC. SCADA10/11, радио и оборудование в этом проходе не менялись
и заново не измерялись. R20 — отдельный следующий native Main из этого r19;
