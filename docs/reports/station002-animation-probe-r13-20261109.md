## Состав диагностической копии

- Screen13 временно показывает диагностику вместо истории запусков CPU.
  Главная кнопка «Диагностика» временно ведёт туда. Сохранены две кнопки
  выхода на главную/к авариям. Исходная рабочая HMI не перезаписывается.
- 31 ND-поле: для каждого ПЧ direct PLC frequency/quality, эти же значения
  **внутри PumpAnimation**, кадр/статус, RX frequency и raw fault. Ни один новый ND не
  является кнопкой ввода или процессной командой.
- В том же вызове PumpAnimation сохраняются frequency/quality вLW920..925.
  LW926 — счётчик вызовов modulo60000, LW927 — карта, увиденная макросом,
  LW928 — его слово аварий, LW929 — состояние связи; LW930=27119 — подпись
  реально исполняемой новой C-версии. VarSettings/порядок входов не меняются.
- Изменение C добавляет только записи в свободные обычные локальные
  LW920..930. Существующие BootAck/управление/защиты/пуск/звуковые службы
  остаются теми же. Новых write inputs к PLC нет, PDW не меняется.
- Все bytes Screen2..12 (включая новую пользовательскую таблицу на Screen9)
  сохраняются точно; инверсия всех перечисленных правок восстанавливает
  исходный SKM. Секционный каталог/locator/EOF пересчитаны.

Частоты показаны сырыми числами; ожидаемое соответствие250=25Гц нужно
сопоставить с реальным ПЧ. Код* — сырой приёмный буфер R2801/2809/2817,
без утверждения о свежести/правильности ответа. Пользователь сообщил A52;
руководство900G/900M, PDFстр58, прямо даёт Err52(A52)=нехватка воды, но
фактическое значение слова на данном шкафу ещё не получено.
