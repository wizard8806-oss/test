## Поведение

- Давление показывается в барах по R2302/100 только при разрешающем R2303=1
  и подходящей карте31/качестве обоих тегов. Достоверный ноль отображается.
  При R2303=0 используется готовый статус контроллера; новая обработка
  отсутствия датчика в ПЛК не добавляется. Электрический обрыв не выводится
  только из этого признака.
- Уставка R2360/100: только показание. Никаких записей в ПЛК или ПЧ нет.
- Частота ПЧ1: R2500/10, проверка R2510; нулевое/ненулевое значение должно
  соответствовать состоянию1/2. Это не нативное подтверждение RUN. Масштаб
  0.1Гц взят из руководства900G, на живом ненулевом значении ещё не проверен.
- Ток и собственная ошибка ПЧ: «Не подключён». В текущем ПЛК ещё нет их
  требуемого экспорта. Отсутствующее чтение не заменяется0А/«аварий нет».
- AlarmLo/AlarmHi показаны сырыми на странице диагностики. Расшифровка
  отложена из-за неразобранных битов AlarmHi8960 на последнем снимке.
- CL50S в новой основной логике не читается. Неизменное давление не служит
  доказательством зависания. GOOD означает доступность OPC-значения, а не
  доказанную свежесть всего маршрута: это явно отмечено на диагностике,
  общий статус по одному GOOD не окрашивается зелёным.
- USB/Service-источник радиоблока и его обработка устаревания остаются прежними.

## Привязки

Основная логика ищет переменные через документированный GetVariableByAddress,
затем проверяет Outer, Address, OPCServerName и ComputerName. Имена импортируемых
переменных могут отличаться; адреса должны быть codex.Device1.<имя тега>, сервер
InSAT.ModbusOPCServer.DA, компьютер localhost. OriginalAsInt исключает двойное
масштабирование при случайном смещении запятой у переменной. При BAD/nil или
ошибке чтения числовое значение не используется.

В карточке текущий стенд/ПЧ1. Это не готовый городской диспетчер. Для будущей
тиражируемой карточки станционные префикс/сервер/модель переносятся в профиль
и шаблоны; текущая копия проекта не должна размножаться на каждый объект.

## Передача пользователю

artifacts/station-process-display-01/Paste-Process-Display-01.ps1 передаётся
целиком inline, поскольку скачивание у пользователя не работает. Это локальная
распаковка с SHA256 и созданием новой копии, без сетевых соединений и изменения
ExecutionPolicy. Готовую папку03 не перезаписывает. Неоднозначный/отсутствующий
путь02 запрашивает в консоли. Изменённые исходные модули не затирает.

1. Сохранить и закрыть Editor/Server/Client Simple-Scada. Gateway/MasterOPC
   продолжают работать.
2. Вставить полный блок PowerShell, получить SAVED с путём03.
3. Открыть её Project.spr в Editor. Импортировать из существующего OPC-сервера
   семь новых тегов PressurePV_x100, PressureSourceOK, PressureSP_x100,
   Vfd1FreqRaw, Vfd1FreqState, AlarmLo, AlarmHi; существующие не дублировать.
4. F9, сохранить, запустить Server/Client этой копии. GUID исходного проекта
   сохранён: параллельно исходную копию как второй проект одного сервера
   не запускать.

Ожидание для последнего стенда: давление недостоверно по ПЛК при отключённом
