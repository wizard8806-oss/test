прошла сравнение всех четырёх строк, четырёх MOV и карты32. SHA256:

Исходный PDW сохранён. Автоматической правки недокументированного бинарного

В обычной таблице M900G_TEST/R5000 строки 1,4,17,18 читают частоту четырёх ПЧ
по одному слову. Предлагается чтение U0-00…U0-06 семью словами в тех же строках.
Число запросов остаётся18, но ответ каждого из этих четырёх запросов длиннее.
Расчёт дополнительной полезной нагрузки48байт/круг не заменяет измерение цикла.

Семисловный ответ предлагается принимать непосредственно в R2800…R2806,
R2808…R2814, R2816…R2822, R2824…R2830. Это **кандидаты**, а не выделенная память:
проверка косвенного/блочного доступа и внешней HMI/OPC-карты не завершена.
Нынешние R2520/R2540 не подходят: они заняты восстановлением/настройками.

У каждой старой частоты D200/D203/D206/D209 найден ровно один закодированный
потребитель во всём проверенном образе — MOV в соответствующий R2500…R2503.
Предлагается изменить лишь источник этих четырёх MOV на слово фактической
частоты из нового блока. Их контакты/условия и существующие регистры частоты
сохраняются. Дополнительное копирование в старые D-буферы не нужно.

Нативное руководство WinProLadder, раздел5.2.4, печатные стр.5-15…5-16,
показывает чтение Holding Registers в Master Data R0. Это подтверждает
доступность R-регистров как приёмника, но не выделение конкретного диапазона.
Источник: https://file.fatek.com/en/PLC/Software/Manual/WinProladder_Manual_en.pdf

У текущей частоты PDU0x1003=4099, шестизначная Modbus-ссылка404100.
У предлагаемого блока PDU0x1000=4096, ссылка404097, длина7. Эти формы адреса
нельзя смешивать. Фактическое окно Edit первой строки теперь подтверждено:
Slave Station1, Read, Data Size1, Master Data D200, Slave Data404100.
В таблице Seq отсчитывается от0: изменяются0,3,16,17. Копия с именем
station_MC_CM55_900G_03.pdw видна в заголовке редактора.

Изменение интерфейса предлагается обозначить map32. Новый SCADA-модуль должен
сначала принять31/32 для прежних полей, а ток и родную ошибку разрешать только
на32 с подтверждённым состоянием данных. Текущая SCADA03 ожидает31: изменение
версии в ПЛК раньше подготовки совместимой SCADA скроет её показания.

R2510…R2513 — состояния **частоты**, включающие проверку её диапазона.
Не называть их без проверки общими признаками достоверности всего нового
блока. Особенно проверить показ кода ошибки, если частота недоступна или
некорректна; отсутствие связи не должно становиться «аварий нет».

(../station-drive-display-02) на текущем ПЛК31 и штатный F8/Syntax Check PDW.
