с прежним stations.json. Шесть сценариев исправления/повторного запуска,
сохранения изменений и CRLF-вставки пройдены. Нативное выполнение исправления
и успешное облачное чтение ещё не подтверждены. Большой блок повторять не нужно.

Run-Radio-Service-Collector-01.ps1 — прототип для одного выбранного stationID.
Станции, группы и выходные каталоги берутся из stations.json; пароли в JSON
не хранятся. Проверены выбор другого IMEI/группы, сохранение данных соседнего

проверены авторизация, CRC, фрагментация, тайм-ауты, повторное подключение и
блокировка второго писателя. 22 случая на настоящем PowerShell/.NET с
независимым TCP-имитатором; кадры сверены с реальной библиотекой TELEOFIS JVM.
