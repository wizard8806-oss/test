# Входы для реализации общего количества насосов

Пользователь принял переходы HMI r1 и 07.11.2026 поручил приступить к N=2/3/4.
`workpack.json` подготовлен из точного восстановленного PLC05. Это входы
для изменения native-копий, **не изменённая прошивка или HMI**.

- Полный порядок строк R5000 сохранён: для2/3/4 отбираются11/14/18 строк.
  Таблица перемешана; обрезка префикса оставляет запросы к отсутствующим ПЧ.
- Восемь одноразовых таблиц перечислены отдельно. Им нужен контроль адресата
  задания и совпадения ответа; изменение только normal poll недостаточно.
- Предложен R2860..R2879; совпадений его прямых16-битных операндов в точном
  образе05 нет, таблицы и их сохранённые R-буферы его не перекрывают.
  Фактическое выделение ещё зависит от полной native cross-reference,
  retentive-настроек и текущих внешних привязок. `physicalAddressesAllocated=false`.
- R2180..R2183 уже заняты ручной частотой; состав AUTO R720..R723 не является N.
- Указаны точки изменения существующей STOP-транзакции, ротации, ручного
  режима, давления, очередей и RUN-выходов. Общая уставка сохраняется в R2100.

Инструмент `tools/prepare_pump_count_workpack.py` ничего не записывает в PDW,
HMI или оборудование. Принимает только точный05, проверяет контрольные суммы
образа/копии таблиц, пишет новый JSON и сохраняет вход. Проверка
`tools/validate_pump_count_workpack.py`:16 случаев PASS, включая сохранение
чтений давления/семисловной телеметрии для каждого установленного ПЧ,
опасный префикс, неверный вход и алиасы выходного файла. Это не испытание
нового ladder или native Simulator. Старый map32 reviewer также проходит.

Продолжение: [реализация PLC и HMI](../../docs/tasks/station002-pump-count-implementation.md).
Не повторять перенос модели/фона и проверенную навигацию r1. Техническая
недоступность GUI остаётся отдельной зависимостью; существующий отказ
доступа не обходить и не повторять тот же desktop-аудит.
