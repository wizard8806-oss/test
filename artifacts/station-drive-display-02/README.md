Карта31 остаётся допустимой для прежних полей. Новые три OPC-адреса читаются
только на32: Vfd1NativeState/R2800, Vfd1FaultCode/R2801, Vfd1CurrentRaw/R2806.
В MasterOPC: HOLDING_REGISTERS, uint16 устройства → uint32 сервера, ReadOnly,
без масштабирования и без дополнительной единицы к PDU. После создания этих
тегов их нужно импортировать в переменные новой копии SCADA.

На32 ток отображается с0,1А. Код неисправности показывается исходным числом,
а пояснение выбирается по руководству900G; неизвестный ненулевой код не
приравнивается к нулю. Надпись «Код0» не является оценкой состояния всей станции.
Ненулевой код получает красный индикатор и приоритет над предупреждением
достоверности давления. Текущие слова AlarmLo/AlarmHi остаются отдельными.

Новые поля требуют GOOD для своих адресов на ожидаемом OPC-сервере/хосте,
карты32, известного нативного состояния900G(1/2/3) и допустимого состояния
частоты из прежней логики. Из-за этого консервативного условия некорректная
частота также скрывает новый ток/код: отдельный общий признак свежести ПЧ
пока не добавлен. Учитывать это при приёмке. Общее подтверждение свежести
всего маршрута и согласованность разных OPC-элементов в одном снимке не
реализованы; прежняя видимая надпись об этом сохранена.
