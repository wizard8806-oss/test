# Отображение режима станции

Для текущего стенда FATEK/900G режим уже опубликован ПЛК в R2300.
Проверены исходные сети30.01…30.04 и95.051…95.058 из загруженного PDW04
с SHA256a25f9b5d2fe006bcb039896bae3989569b08e1b1adc4b503a755bfd5e3b22993.
Нативные мнемоники получены исходным Prolad18.dll, выполняемым в изолированной
x86-среде без импортированных функций ОС; это не нативная GUI/F8.
Доказательства: native-source-review-2026-10-30.json.

Коды:0—СТОП;10,11,12—АВТО;20,21,22—РУЧНОЙ;90—ошибка селектора.
Числа11/12 и21/22 показывают этап подготовки/разрешения или наличие команды,
не являются отдельным подтверждением вращения двигателя. Неизвестный код
сохраняется в тексте. Код0 означает СТОП только при допустимом качестве
привязки и подтверждённом изменении общего счётчика ПЛК. На31, без нового
тега, после истечения15с, паузы таймера или потери качества показывается
«НЕТ ДАННЫХ». Остановка CPU сама по себе не трактуется как выбранный СТОП.

Установка создаёт Desktop/codex_diag_06 из работающего codex_diag_05.
Меняется только исходник StationDiagnostics в новой копии; прежние страницы,
переменные и серверы, запись радио и таймер сохраняются. Радиосборщик не
перезапускается. Новых команд управления и записей в ПЛК не добавлено.
Новый тег MasterOPC: codex.Device1.StationMode, HOLDING_REGISTERS/PDU2300,
устройство uint16, сервер uint32, ReadOnly, без масштабирования и сдвига+1.
Его нужно импортировать в новую SCADA-копию, выполнить F9, сохранить и
запустить её Server/Client вместо прежней копии. ПЛК для этого не меняется.

Режим виден в заголовке вкладки «Станция», подробность режима—под основным
статусом, а на «Диагностике»—рядом с версией карты. Новых объектов страницы
не создаётся. Если в диалоге источника выбран родительский Projects,
установщик принимает содержащуюся в нём папку codex_diag_05; неверный выбор
отклоняется до копирования с пояснением требуемой структуры.

Проверены59 прежних утверждений карты31,281 утверждение свежести и режима,
10сценариев реального PowerShell/Linux копирования, сохранение радио/таймера
и наличие17 используемых имён среди32 прежних объектов страниц.
Результат: validation.json. Нативные Windows F9 и надпись рядом с реальным
селектором этими офлайн-проверками не подтверждаются.

31.10 пользователь ответил «работает» после установки и задания сверить режим.
Отображение принято по этому сообщению; отдельных снимков и значений кодов
каждого положения переключателя нет. См. native-observation-2026-10-31.json.
Рабочая SCADA-копия теперь codex_diag_06; повторная установка не требуется.

Работа по уставке продолжается отдельно: из текущего файла теперь подтверждён
диапазон0,10…11,90бар с шагом0,10бар и существующий признак применения M969
с кэшем D672/D673. Зеркало R2360 само по себе не подтверждает применение ПЧ.
Кнопка уставки и экспорт этого подтверждения данным пакетом не добавлены.
