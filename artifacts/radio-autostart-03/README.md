# Радио03: пакет автоматического запуска для одной станции

Пакет подготовлен для Windows10/Windows PowerShell5.1 x64. На ноутбук ещё
не установлен; работа DPAPI/ACL/Планировщика/запуск без входа не проверены.
Текущая ошибка публикации02 не считается исправленной этим пакетом.

Исполняемый обмен — точный C# transport сборщика02. Версия03 меняет способ
получения паролей, диагностику и коды завершения, сохраняя Service9336/ARADIO1
и начальный collector.lock. Main50008/USB/ПЛК не используются. Runtime03 не
содержит Read-Host; пароли однажды вводятся в локальный установщик и шифруются
DPAPI LocalMachine. Код/конфигурация/шифротекст устанавливаются в закрытый
SYSTEM/Admin каталог `%ProgramFiles%\AutomatikaRadioAutostart03`.

Задача `Automatika-Radio-Service03` работает от SYSTEM, скрыта, запускается
при включении ПК с задержкой30с, без входа оператора. Повторный параллельный
запуск игнорируется. После локального отказа — не более3 повторов с интервалом
1мин; обычный сетевой backoff остаётся в коде02. Protocol fatal, включая
CLOUD_SESSION_REPLACED, публикуется и завершает процесс с0, чтобы Планировщик
не запускал конкурирующую сессию повторно. Нулевой task result в этом случае
не означает исправность радио: проверять ARADIO1/status и last-error.json.

Локальный CLI сначала заканчивает текущую UI-работу и выполняет
[чтение причины публикации02](../../docs/tasks/radio02-publish-readonly-check.md).
Дальше следует [порядок автономизации](../../docs/tasks/radio-autonomous-startup.md).
Запускать только проверенную копию пакета из актуального Git.

```powershell
# Подготовка: ввод паролей локально, регистрация ОТКЛЮЧЁННОЙ задачи.
.\Manage-Radio-Autostart03.ps1 -Mode Prepare

# После устранения/проверки публикации и штатной остановки старого писателя.
.\Manage-Radio-Autostart03.ps1 -Mode Enable -PublicationVerified

# Отключение автозапуска и штатный stop-marker только работающей своей задачи.
.\Manage-Radio-Autostart03.ps1 -Mode Disable

# Удаление своей задачи; runtime/credentials/файлы станции сохраняются.
.\Manage-Radio-Autostart03.ps1 -Mode Remove
```

Prepare не перезаписывает существующий каталог/задачу. При неудачной подготовке
оставшийся закрытый каталог сохраняется для разбора; повторная установка
не затирает его. Enable сверяет source/config/task/ACL и lock перед запросом
запуска. Флаг PublicationVerified — отметка локального исполнителя о выполненной
проверке, сам пакет не доказывает исправность radio.txt. После StartRequested
нужно проверить PID/seq/возраст/фактическую учётную запись и состояние SCADA.

Disable/Remove сначала отключают триггер, запрашивают graceful-stop через
radio.stop и ждут до90с. При незавершённом stop возвращается ошибка, задача
остаётся отключённой; все PowerShell-процессы не завершаются. Состояние
текущей рабочей конфигурации и возможность возврата02 нужно сохранить.

Локальная диагностика03 пишет только UTC/PID/код/type/HResult в last-error.json,
без текста исключения/паролей. Статус может относиться к прежней попытке —
сопоставлять время/PID. Набор station/config/data/credential files остаётся
приватным: в Git только шаблоны, payload и manifest. Многостанционный scheduler
и реальная Windows-служба SCM этим пакетом не реализованы.
