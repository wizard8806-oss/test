## Получение на Windows

Локальный CLI загружает `tools/apply_hmi_layout_recipe.py` и этот
`layout-recipe.json` по закреплённому GitHub-коммиту в новую разрешённую
папку. git fetch/правки .git и доступ к GUI для создания копии не требуются.
Исходник — ровно присланный пользователем файл; если он недоступен из
исполнителя, попросить скопировать его в конкретную разрешённую папку.
Если SHA отличается, новый рецепт по догадке не создавать.

```text
python apply_hmi_layout_recipe.py --source "pump_station_unified_2-4_draft.skm" --recipe layout-recipe.json --out "pump_station_unified_2-4_layout_r1.skm" --report layout-report.json
```

Нужны Python и стандартная библиотека. Выход и отчёт должны быть новыми
файлами в существующей разрешённой папке. Пользователь открывает новую копию
в SKTool и запускает Offline Simulator. Проверить навигацию, читаемость
правой панели/левой частоты, общий ряд кнопок и сообщения AUTO. Результат
схемы `layout-map.png` не является кадром native Simulator.

**Границы проверки в cloud:** выполнены статическая проверка на реальном
файле и 22 синтетических случая проверки инструмента. SKTool/компиляция/
Simulator в cloud не выполнялись; флаги native=false в
`verification-summary.json` описывают именно этот этап создания кандидата.
Переключение 2/3/4 и параметр количества в ПЛК этим рецептом не реализованы.

не подтверждает данные, связь, оборудование или реализацию количества.
