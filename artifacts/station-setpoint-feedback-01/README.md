Рабочая уставка—R2100, зеркало—R2360. Допустимая текущим ПЛК уставка:
0,10…11,90бар, шаг0,10бар. Существующий обработчик проверяет F5-01 ведущего

хранят подтверждённые адрес ведущего ПЧ и давление*100. M969 подтверждает
соответствие этого кэша текущим ведущему и уставке при разрешённом контексте.
M968—защёлка ошибки применения; D676/D677—код координатора и подробность,

WM968—16бит M968…M983. В R2856 бит0—ошибка M968, бит1—подтверждение M969.
Остальные биты сохраняются, без дальнейшего контракта не расшифровываются.
Оба младших бита1 одновременно—недопустимое сочетание для будущей SCADA.
Признак версии R2850=1 отделяет это дополнение от неинициализированных адресов.
Числа D672/D673 при M969=0 могут быть прежним кэшем, а не новым результатом.
Это зеркало состояния, не подтверждение отдельного requestID ПЛК и не
согласованный атомарный снимок с остальными OPC-тегами.
